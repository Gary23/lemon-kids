- 复用认字端根层恢复机制，不修改认字端功能；不清除任务端本机待同步记录。

## 背景与目标

已连接华为 BZT3_AL00 平板，线上任务包 `com.lemonkids.kidtask`。现场截图确有数量读取失败；日志同时显示番茄上传与查询遭遇未授权。修复长期驻留、后台恢复或认证失效后业务无法恢复的问题，并让任务保存失败原因可见。

## 非目标与约束

- 不改番茄时长、计时/响铃规则、积分规则、任务排序及其他应用功能。
- 不清除应用数据、不卸载、不丢弃待同步番茄，不在真实任务上擅自执行完成/撤销进行试验。
- 不以假零值、假成功或无限重试掩盖故障；不记录令牌、绑定码和完整认证响应。
- 设计批准后才能改代码；自动测试通过并经用户安装确认后才能覆盖安装；人工验收后才能提交推送及标记完成。

## 依赖及跨模块影响

调用共享 Auth、TaskRepository、PomodoroRepository 和现有 SessionRecoveryCoordinator。共享改动须隔离为任务端启用或保持其他端原行为，编译验证受影响模块。不预设需要修改 Supabase 数据库、云函数或部署 SQL；现存暂停兼容 SQL 部署状态另行保留，不将其当作本次未授权故障的已证实根因。

## 验收标准

1. 有效登录状态下番茄数量能正常读取；未同步记录在认证恢复后按原 sessionId 补传并与远端核对，不重复、不丢失。
2. access token 过期、会话丢失、服务端认证拒绝时，执行受控恢复；恢复失败明确引导现有登录恢复界面，不永久只显示读取失败。
3. 今日任务与日历的完成/撤销成功后状态可重新读取；失败恢复原状态及积分、明确提示，不播放成功得星效果。
4. 长驻前台跨过令牌有效期、后台恢复、断网后重试与不可恢复会话均有自动测试覆盖，并在指定平板人工验证关键路径。
5. 不因超时或未知响应盲目重放任务写操作；账号切换/协程取消不继续旧账号请求，其他应用认证行为不扩展修改。
