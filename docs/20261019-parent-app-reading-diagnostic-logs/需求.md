# 家长端查看认字朗读诊断日志

- 需求编号/目录：`20261019-parent-app-reading-diagnostic-logs`
- 日期：2026-10-19
- 应用范围：`parent-app`；依赖 `cloud-functions/evaluate-reading` 的受控查询能力和腾讯云 CLS
- 提出人：用户

## 原始需求

> 针对这个需求再补充一个功能，我希望在家长端增加一个入口去实时查询服务器上的查询诊断记录的日志

## 背景与目标

认字端新增未通过朗读诊断上报后，家长需要在家长端查看自己孩子的最近记录，以便在现场重现问题时核对服务器收到的腾讯逐项结果、标红位置和判定原因，而不必打开腾讯云控制台。

## 范围、约束与依赖

- 仅实现家长端入口和家长可用的受控查询接口；认字端的上报由[独立需求](../20261019-kid-literacy-app-failed-reading-diagnostics/需求.md)处理，分别设计确认和测试。
- 数据来源为 `evaluate-reading` 写出的 `READING_EVAL_FAILED` 结构化日志，经腾讯云日志服务 CLS 查询；不向家长端下发腾讯云 CAM 密钥，也不开放任意日志查询。
- 服务器必须确认当前 Supabase 登录者为家长、所选孩子属于其家庭，才可按孩子哈希查询限定日志主题。页面不得显示其他家庭的记录。
- 页面打开后周期刷新，另提供手动刷新；显示最近刷新时间。日志投递与索引可能有短暂延迟，“实时”指持续读取最新可查询日志，不保证零延迟。
- CLS 日志投递、字段索引、只读查询权限和日志保留期属于部署前提。缺少配置时页面明确提示查询不可用，不显示伪造空列表。
- 开发、自动测试、安装确认、人工测试确认按 [`docs/README.md`](../README.md) 独立执行。

## 非目标

- 不展示应用所有服务器日志，不读取录音，不提供日志删除、编辑或导出。
- 不改变现有“设备日志”页面或认字端判定规则。
- 不在本需求中新增已通过评测的采样；此页面只展示认字端实际已上报的未通过回调。

## 验收标准

1. 家长端“我的”有“认字诊断记录”入口，可选择当前家庭孩子查看最新未通过朗读记录。
2. 页面显示记录时间、字/词/句、目标文本、标红位置与原因、腾讯逐项评分及返回字；明确区分“腾讯返回字段”与孩子实际说出的内容。
3. 打开页面自动加载、页面可见时定期刷新、支持手动刷新，并展示上次成功刷新时间、加载中、空列表、失败和日志服务暂不可用状态；切换孩子后旧孩子记录立即清空。
4. 后端只返回当前家长家庭内所选孩子的 `READING_EVAL_FAILED` 事件，限制查询时间范围、返回条数和字段；越权孩子或非法参数不能读取日志。
5. 日志服务有投递延迟时，页面不误称“已包含刚才的录音”；上报失败的回调不会出现在列表中。
6. 自动测试覆盖家长身份、跨家庭隔离、查询过滤、分页或条数上限、空结果及服务故障；人工测试可在认字端制造一条未通过记录并在家长端刷新后看到同一 `attemptId` 的内容。

## 已验收的补充与缺陷（2026-10-19）

- 补充：新失败记录可展开查看经安全筛查的腾讯评测原文 JSON，保留原字段名、层级和值并可复制；旧记录、无效或超限原文显示未保存原因。认字端采集见[独立补充流程](../20261019-kid-literacy-app-failed-reading-diagnostics/需求.md)。
- 缺陷：CLS 查询复用既有 `LITERACY_TENCENT_REGION` 与 `LITERACY_STS_SECRET_ID`／`LITERACY_STS_SECRET_KEY`，只新增 `LITERACY_CLS_TOPIC_ID`；CAM 身份获目标主题的 `cls:SearchLog` 权限。查询错误在 SCF 留脱敏错误码和请求 ID，家长端保持普通提示。
- 缺陷：修复 CLS 日志包装的事件解析及成功却为空的问题，继续严格核对孩子哈希；上次刷新及记录时间按设备本地时间显示。真实失败日志现可在家长端查到。
- 中文说明作为独立的[家长端需求](../20261019-parent-app-diagnostic-chinese-labels/需求.md)验收：记录显示中文标签，字段说明页引用腾讯官方文档并解释 `PronAccuracy=-1` 等字段和本应用原因代码。
