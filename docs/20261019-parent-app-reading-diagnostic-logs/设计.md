# 设计：家长端认字诊断记录

## 问题分析与目标

家长端已有“我的 → 设备日志”的入口和按孩子查看记录的交互，但它的数据源是设备状态记录。新认字诊断记录计划写入 `evaluate-reading` 的 SCF 日志，并经 CLS 投递；家长端不能直接使用 CLS 查询密钥，也不能看到无关服务器日志。

目标是在家长端按所选孩子持续读取最近的未通过朗读记录，并可展开查看腾讯返回的逐项字段和客户端为什么标红。

## 页面与交互

1. 在“我的”增加“认字诊断记录”卡片，进入独立子页面。顶部选择当前家庭孩子；默认第一个孩子，可手动切换。切换时立刻清空前一个孩子的记录和错误状态。
2. 首次进入及页面重新可见时请求最新记录；可见期间每 15 秒刷新一次，另提供“刷新”按钮。页面离开或进入后台时停止轮询；并发请求合并，不让慢响应覆盖新孩子结果。
3. 默认查询最近 24 小时，按服务器时间倒序返回最多 50 条；页面显示记录时间、目标类型与文本、标红字位、原因摘要。点开单条看 `attemptId`、`textMode`、腾讯逐项 `Word`、`PronAccuracy`、`MatchTag` 等白名单字段。
4. 页面明确标注：字段是腾讯评测结果和客户端判定，不能证明孩子实际读出了哪个字。显示上次成功刷新时间，以及“日志可能稍后出现”的说明；空结果、网络故障和服务端配置缺失分别提示。

## 服务端数据流与权限

1. 在 `cloud-functions/evaluate-reading/index.js` 增加只读动作 `list_failed_reading_diagnostics`，入参仅允许 `childId`、受限的时间窗口和分页游标；不接受任意 CLS 查询语句、主题 ID、事件名或孩子哈希。
2. 云函数用现有 Supabase JWT 鉴权取得调用者 ID，查询 `users`，必须满足 `role=parent`、有 `family_id`；再验证 `childId` 对应 `role=child` 且 `family_id` 相同。服务端根据已核对孩子 ID 算出与上报相同的哈希。
3. 云函数用仅服务端持有的 CLS 只读凭证查询配置好的 `evaluate-reading` 日志主题，过滤固定事件名、孩子哈希及时间范围，只解析白名单字段并按时间倒序限制结果量。客户端只收到该孩子的记录；任何 CLS 原始日志行、其他函数事件、底层查询语句与密钥均不返回。
4. 部署配置要求 `evaluate-reading` 的日志投递到 CLS、`event` 和 `childHash` 等字段可检索，并提供主题 ID、地域及最小 `SearchLog` 类只读权限。若当前没有可用的 CLS 投递或索引，部署前须补齐并通过真实样本确认；接口返回明确的服务不可用状态。
5. 新动作不影响原有认字端调用。查询费用与流量受时间窗口、条数和轮询间隔限制；服务器记录查询错误时不得打印密钥、Token 或返回其他家庭数据。

## 涉及文件与跨模块依赖

- `parent-app/src/main/java/com/lemonkids/parent/feature/profile/ProfileScreen.kt`：新增入口。
- `parent-app/src/main/java/com/lemonkids/parent/navigation/ParentNavGraph.kt`：新增子路由。
- `parent-app/src/main/java/com/lemonkids/parent/feature/profile/`：新增页面及 ViewModel，请求现有 Web 函数，维护孩子切换、刷新和展开状态。
- `cloud-functions/evaluate-reading/index.js` 和 `package.json`：新增家长查询动作和必要的 CLS SDK 依赖；此共享云函数改动归入本家长端流程，并注明依赖认字端 `READING_EVAL_FAILED` 日志契约。
- [认字端设计](../20261019-kid-literacy-app-failed-reading-diagnostics/设计.md)负责输出单行 JSON、固定事件名与稳定孩子哈希；须先完成该日志契约和 CLS 配置，再验收本页面。
- 无数据库迁移。若 CLS 实际日志格式不支持所需字段索引，先调整日志投递／索引配置，不放宽服务端过滤或直接暴露原始日志。

## 验证、风险与回滚

- 自动测试覆盖家长身份、家庭内孩子、跨家庭或孩子身份拒绝、CLS 查询过滤、50 条上限、字段白名单、服务不可用和孩子切换后的异步竞态；执行家长端构建及云函数相关测试。
- 实机联调以一条带 `attemptId` 的认字端失败回调为样本，确认 CLS 中可查、家长端展示同一条且其他孩子看不到。CLS 投递有延迟，因此以页面成功刷新后查到记录为验收，不承诺秒级确定到达。
- 云函数源码或依赖变更后生成符合仓库约定的新部署 ZIP，`unzip -l` 核验根目录并更新其 README。自动测试后取得家长端安装许可，等待人工测试确认；不与认字端共用门禁结论。
- 回滚时移除入口与查询动作；日志上报可继续用于后台排查。CLS 权限和索引配置可单独撤销。

## 待用户确认的设计决策

- 入口置于“我的 → 认字诊断记录”，按孩子展示近 24 小时最多 50 条，每 15 秒刷新，并支持手动刷新。
- 直接查询服务器投递到 CLS 的诊断日志，由云函数做家长与家庭权限校验；家长端不持有云日志密钥。
- 页面展示评分和标红原因，不声称能识别孩子实际读出的字；只显示认字端已上报的未通过记录。
- 此家长端需求与认字端上报需求分别取得设计批准、安装许可和人工测试确认。

## 补充与缺陷的最终设计及确认

用户分别批准腾讯原文展示、复用既有地域与密钥、CLS 查询失败诊断、空结果与时间修复方案。新失败诊断的受限腾讯 JSON 经云函数校验后保存在同一事件中；家长查询仍按家庭、孩子、24 小时及 50 条限制返回，并对旧记录说明原文缺失。CLS 查询仅额外读取主题 ID，复用既有地域与 CAM 密钥；必须在现有 CAM 子用户上授予目标主题 `cls:SearchLog`。错误日志只含错误码、请求 ID 和安全计数。查询按固定事件检索，解析 `SCF_Message` 等包装后再核对孩子哈希；时间在家长端按设备本地时区显示。以上设计均在代码修改前获用户明确批准，2026-10-19 人工验收通过。
