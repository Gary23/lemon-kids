# 设计：单字朗读通过分数调整为 50 分

## 现状与方案

客户端 LemonLiteracyApp.kt 的 readingPronunciationThreshold 当前为单字 60、词语 50、句子 30；逐字判错与失败原因共用该函数。

将单字阈值改为 50，统一为 **字 50 / 词 50 / 句 30**。保留目标片段 MatchTag=0 的硬性前提，等于阈值通过；兼容 0～1 与百分制评分。分数缺失或无法解析且 MatchTag=0 时仍按匹配回退通过；漏字和非目标音段处理不变。待认识和已认识练习共用规则，不修改 UI、星数要求或已保存进度。

## 文件与依赖影响

- kid-literacy-app/src/main/java/com/lemonkids/kidliteracy/LemonLiteracyApp.kt：调整阈值；失败原因自动使用同一新阈值。
- kid-literacy-app/src/test/java/com/lemonkids/kidliteracy/ReadingEvaluationRulesTest.kt：单字边界改为 49/50，保留词句、匹配标记与缺失评分测试。
- cloud-functions/evaluate-reading/index.js：当前诊断版本硬编码为 match-tag-0-pron-accuracy-60-50-30-v2，需同步为 match-tag-0-pron-accuracy-50-50-30-v3；历史日志不改写。部署后旧 APK 的新诊断可能仍被标记为新版本，因此需协调相关 Pad 升级，不能以版本字段推定旧客户端阈值。
- 云函数相关测试：核对诊断版本与既有原因兼容性。

不改变请求结构或数据库；不修改 parent-app，其旧阈值解释文案不在本次范围。

## 测试与交付

自动测试覆盖单字 49/50、词语 49/50、句子 29/30，分数量纲兼容，MatchTag 非 0/缺失/不可解析以及分数缺失回退。执行认字端单元测试和 APK 构建、云函数测试。

云函数变更后生成 evaluate-reading-web-20261110-character-score-50.zip，根目录包含 index.js、server.js、scf_bootstrap、package.json、package-lock.json、生产 node_modules；用 unzip -l 核验并更新云函数 README 当前部署包名。记录部署状态，不将打包等同于部署。

自动测试完成后请求安装确认；安装后等待用户朗读人工验收，不提前推送或标记完成。

## 项目文档同步

人工验收后更新 kid-literacy-app/docs/LEARNING-RULES.md 的单字分数；核对应用 README 并按需同步。云函数 README 更新部署包及诊断版本说明。历史需求文档保留历史规则，不回写。

## 风险与回滚

降低单字门槛可能放过部分含混读音；人工验收覆盖正常儿童发音与明显错读。回滚时恢复原单字门槛及对应诊断标识，不重算历史星级。
