# 柠檬任务本地调试包与打包流程

- 需求编号：20261030-kid-task-app-local-debug
- 日期：2026-10-30
- 应用范围：`kid-task-app`（柠檬任务）；包含该应用所需的共享认证适配与本地数据库接口。
- 提出人：用户

## 原始需求

> 柠檬也按照家长端这个方案做一个本地调试包打包的流程，需要的数据你都自己找一下

用户补充约束：

> 记得要在app的登陆页和app内部的某个位置增加修改本地ip地址连接的功能

登录入口对应柠檬任务的绑定码登录页；应用内入口放在“我的成长”设置区。

## 背景与目标

现有柠檬任务 debug 包没有独立本地包名和手机端服务地址入口。共享模块已有家长端使用的本地 Supabase 配置，但孩子端的绑定码恢复、桌面卡片与提醒需要适配环境切换。本地服务已经具有任务和奖励等基础业务结构，但缺少孩子端成长快照接口。

目标是形成可重复执行的本地调试 APK 打包流程，连接现有 `lemon-kids-local`，与家长端本地包共同验证布置任务、孩子绑定、任务完成/撤销、奖励与成长等业务。

## 约束与依赖

- 仅显式本地 debug 使用独立包名 `com.lemonkids.kidtask.local`；默认 debug、release 继续使用各自原有配置。
- 复用 `localSupabase=true`、`localSupabaseUrl` 和 `localSupabaseAnonKey`；本机已经配置本地地址及公开 anon key，不要求用户补交配置或密钥。
- 目标 API 为 `54421`，Studio 为 `54423`；`8765` 是服务控制页面，不是应用 API。
- 手机通过电脑的私有 IPv4 地址访问；模拟器和 USB 转发按家长端方式使用。
- 本地账号、家庭、绑定码、任务和奖励属于本地库；不自动复制线上账号、业务数据或会话。
- 工作区原有未提交的任务计时改动已于 2026-11-09 按用户决定整体废弃，本流程不再涉及计时、用时或计时会话行为。
- 设计批准后才能改代码；自动测试后取得设备安装和现有数据库部署确认；人工验收通过前不推送、不标记完成。

## 验收标准

1. 一条明确命令可重复生成带本地标识的独立 APK，同时输出包名、版本、文件路径和 SHA-256；配置缺失或校验失败时明确失败，不交付旧 APK。
2. 启动、绑定码登录页、“我的成长”设置区和会话恢复弹层均能进入本地服务地址设置。登录页和设置区显示当前 `IP:端口` 及“修改本地服务地址”入口；未登录、登录后及服务不可达时均可修改。地址合法且可达才能保存并继续，不可达时保留输入供修改重试。
3. 地址相同时保留会话；更换地址后清除旧会话、保存的绑定码及相关本地任务快照，通过受控重启统一切换客户端与 RPC。
4. 本地包保持 `type="task"` 和 Android 设备标识的绑定规则；可以使用同一本地家长端生成的绑定码登录，重启后保留会话，并支持既有恢复机制。
5. 验证任务列表/日历/未来计划、完成/撤销、积分、奖励兑换/取消/使用和成长数据；空数据如实显示，不以演示记录掩盖接口缺失。
6. 数据验证使用隔离环境中的合成家庭，覆盖孩子自身权限、跨家庭拒绝、家长及匿名调用限制；现有本地数据不被清空或批量改写。
7. 交付 APK、打包用法及手动测试步骤；设备安装与数据库应用均在测试结果可审阅后取得明确确认。

## 范围边界

本流程只验收柠檬任务。共享模块变动限于本地任务包识别及必要的会话/环境边界，需回归家长端兼容性。本地成长 RPC 归入柠檬任务依赖，不改变家长端功能。其他应用、线上部署、外部云函数、通用 Supabase、控制台改造和头像编辑能力不在范围内。
