## 构建与产物

1. 在 `kid-task-app/build.gradle.kts` 的 debug 构建中识别 `-PlocalSupabase=true`，添加 `.local` 包后缀、`-local` 版本后缀及“柠檬任务·本地”启动器标识。
2. 复用 shared 现有配置优先级：同名 Gradle 参数、未提交的 `local.properties`、环境变量。仅使用本地公开客户端 key，不把 service-role key 写入 APK。
3. 标准构建命令：`./gradlew :kid-task-app:assembleDebug -PlocalSupabase=true`。
4. 新增 `kid-task-app/scripts/build-local-debug.sh`，从任意目录定位仓库并运行任务端/共享模块单元测试和本地构建；校验本地 URL/anon key、APK 包名/版本和实际生效的环境资源，再生成明确命名的交付副本及脱敏元数据。测试或构建失败不沿用旧产物；不自动安装、启动或迁移数据库。
5. 交付副本固定为 `kid-task-app/build/outputs/apk/local-debug/kid-task-app-local-debug.apk`，元数据包含 SHA-256、版本、构建时间及目标地址，不包含 key、token 或账号资料。默认调试产物仍由 Gradle 管理。

## 地址设置与认证边界

- 在 `KidTaskApp` 初始化共享环境；在创建导航图、AuthViewModel 和业务客户端前展示本地地址页。普通 debug/release 不展示、不读取本地地址偏好。
- 参照家长端实现应用内 `feature/local/` 地址页、解析器和前台辅助重启 Activity，保持横屏可操作。不为复用界面而扩大修改家长端；共享环境配置继续使用现有入口。
- 仅接受私有 IPv4 或 `127.0.0.1` 与显式端口，默认端口 `54421`；保存前异步请求 `/auth/v1/health`，连接/读取分别设短超时。错误保留输入并可重试，无线上回退。
- 启动页、绑定码登录页、“我的成长”设置区及阻断式恢复弹层均提供本地地址入口，防止旧地址不可达后无法退出恢复界面。绑定码输入/登录按钮附近显示当前 `IP:端口` 和“修改本地服务地址”；应用内在“我的成长”设置区增加同名设置项并显示当前地址，两处复用同一地址页。入口不依赖接口请求成功，不因登录错误或服务不可达而隐藏；仅显式本地调试包显示。
- 同地址可达时继续使用原会话；换地址时停止旧页面的业务动作，清除持久化 Auth 会话与任务绑定码，清理桌面任务快照、首页本地顺序等环境相关状态，保存成功后由前台辅助进程接管并重启。辅助 Activity 不导出，核验目标进程属于当前应用，失败提供重试。
- 本地任务提醒记录每次切换独立的环境标识，切换后取消旧环境提醒/通知，接收端拒绝过期环境的提醒，即使地址切回原值也不复活旧提醒；桌面卡片切换后显示新环境内容或未绑定/空状态，不沿用旧任务快照。
- 共享 `AuthViewModel` 精确识别 `com.lemonkids.kidtask` 与 `com.lemonkids.kidtask.local`，保持线上任务包及其他应用既有规则；必要的绑定缓存清理以明确方法封装，避免散落偏好键。
- `.local` 与原包拥有独立应用数据；相同本地服务内仍支持绑定码恢复。地址变化视为环境切换，重新输入该服务生成的 task 绑定码。

## 本地数据与业务验证

1. 使用现有家长端本地注册/家庭/绑定码流程提供测试入口；自动验证在隔离副本创建两组合成家庭、孩子、任务和奖励，不使用线上账号或向现有库批量注入示例记录。
2. 核对客户端调用的表字段、RPC 签名/返回结构和孩子权限，覆盖任务、积分、奖励、成长、分类读取及使用统计。参考现有 `supabase/tests/verify_local_parent_business.py` 隔离方式，增加柠檬任务专用验证；不用管理员调用成功替代普通客户端验证。
3. 为缺失的成长快照新增本地增量 SQL 与应用/验证入口；补齐既有孩子端上报逻辑所需的本人使用统计旧快照删除权限，只允许当前孩子删除本家庭本人记录，禁止匿名、其他孩子和家长删除；迁移本身不删除任何记录。复用已审查的成长计算，不执行历史 SQL 全量初始化。只为当前 Auth 孩子返回本人快照，匿名、家长不能调用，验证跨家庭隔离及空结果结构。
4. 自动测试先在隔离环境验证迁移、重复执行、权限和原数据保留。对当前 `supabase_db_lemon-kids-local` 先只读预检，取得部署确认后事务应用，保留原表与业务数据，生成不含敏感信息的部署回执。
5. 奖励图片验证实际本地 Storage 签名与读取链路，核对 URL 可由测试设备访问；若现有配置暴露容器/电脑回环地址，在本应用调用范围内处理必要兼容，不通过图片占位掩盖失败。
6. 任务计时功能已整体废弃，本流程不再涉及计时、用时或计时会话规则。若检查发现超出本地接入的业务缺陷或需要改写现有数据，列明影响并走对应流程。

## 自动测试与交付验收

- 单元测试覆盖地址边界、精确包名识别、环境切换时会话/绑定码清理和受控重启目标验证；回归任务端现有测试。
- 构建本地 debug、普通 debug、release，检查包名、版本、启动器标识和生效配置，确认默认与发布包不受本地开关影响；共享改动回归家长端相关测试/构建。
- 执行打包脚本，核对交付副本与元数据、SHA-256 和失败路径。
- 隔离 Auth/REST/RPC 验证孩子登录、会话、任务完成/撤销、奖励事务、成长快照和跨家庭限制；Storage 用实际 HTTP 验证。
- 自动验证后给出 APK 路径、测试结果及数据库变更清单，取得安装/部署确认，再等待人工测试。
- 人工测试包含同 Wi-Fi 连接、家长生成绑定码、孩子登录、四个 Tab、积分、奖励、成长、杀进程后恢复、地址错误/切换、桌面卡片和正式包共存；分别验证未登录时从绑定码登录页修改地址、登录后从“我的成长”设置区修改地址，以及旧服务不可达时仍可进入修改页；提供逐步操作及预期结果。

## 风险与回滚

- 本机默认 `127.0.0.1` 仅适合 USB reverse；真机使用电脑私有 IP，模拟器使用 `10.0.2.2`。地址页面明确提示网络前提。
- Hilt 单例与自动恢复可能持有旧环境，采用完整进程切换并清除旧凭证，验证 SDK、RPC 和后台入口一致。
- 原代码包含未提交的任务计时改动；该功能已于 2026-11-09 整体废弃并从工作区移除，其余本地调试改动不被覆盖或暂存。
- APK 回滚只卸载/替换本地包；数据库失败事务回滚，已应用接口以兼容迁移修正，不删除已有账号、任务或积分。
