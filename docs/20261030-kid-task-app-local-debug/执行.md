## 验证中发现与处理

- release 首次压缩遇到可选 `org.slf4j.impl.StaticLoggerBinder` 缺失；参照家长端添加同样的精确 `-dontwarn`，后续 release 构建通过，不增加日志实现。
- 匿名访问核心任务表通过 RLS 返回空列表，验证按“401/403 或无记录”判断，并在写入真实合成任务后再验证不可读取，不放宽源库授权。
- 临时 Storage 启动在并行构建负载下超过原 45 秒等待，改为有进度及进程状态检查的最长 180 秒等待；曾有一次临时会话刷新未通过，后续保留副本及最终完整链路均通过，未改动现有 Auth 配置。
- 当前孩子端按孩子/日期先删旧统计再上报，本地旧基线缺少 DELETE 权限。增量只允许同家庭当前孩子删除本人记录；验证其他孩子、家长及匿名不能删除，迁移本身不删除任何数据。
- 核验 Supabase 2.6.1 / multiplatform-settings 1.1.1 默认会话键与存储文件。重启辅助进程不依赖仅在主进程初始化的默认 Context provider，直接用 Android Context 同步清理该会话键，避免初始化失败或异步删除尚未落盘。
