## 原始需求

> 开始新需求，本次需求需要你对"我的"页面的ui与效果图ui进行复核，现在我认为在尺寸方面是有差异的，实际运行在pad感觉所有元素有太大了，你需要再确认一下尺寸的问题，对于ui有问题的的地方进行修改

## 背景与目标

上一轮已按效果图校准本应用“认字”首页，但“我的”页仍沿用初版通用页面头、120 dp 高入口卡和 220 dp 宽统计卡。目标是以同一目标 Pad 上的实际窗口为依据，复核“我的”页标题、资料区、统计、六个入口、间距和固定导航的视觉比例，修正明显偏大的元素，使常见数据下呈现参考图的两列三行结构。

## 范围与约束

- 仅调整 `kid-literacy-app` 的“我的”页展示和必要的页面专用布局计算；保留六个入口、真实头像/孩子姓名、累计识字缓存条件、导航和各子页行为。
- 参考图为 1536×1024 px 的视觉坐标，不直接当 dp；适配安全区、横屏比例、长姓名、大字体和至少 48×48 dp 的触控区域。
- 不改其他应用、首页任务卡、子页业务布局、共享模块、接口、数据库或云函数。
- 遵循 [`docs/README.md`](../README.md)：设计获明确批准后改代码；自动测试后取得安装确认；设备人工测试确认前不推送或标记完成。

## 验收标准

1. 在 BZT3-AL00 横屏、320 dpi、字体倍率 1.0 下，“我的”页的信息区、统计卡、三排入口和底部导航按参考图逐项校准；六个入口在常见姓名及累计数条件下保持两列三行，整体大小不再明显超过参考比例。最终已按补充需求移除独立页头。
2. 六个入口文案、插画、点击区域完整；固定导航可见且不遮挡最后一排，滚动到底仍能操作所有入口。
3. 真实头像、姓名及累计数规则不变；无本地字库缓存时隐藏统计卡；长姓名、大字体和较窄横屏可增高或滚动，不裁切内容，触控区域至少 48×48 dp。
4. 自动验证完成后，经用户确认安装到指定 Pad，由用户对照效果图人工检查视觉比例和操作。

## 跨模块影响

无。此需求只涉及 `kid-literacy-app` 的 Compose 页面展示。

## 人工测试期间归并的补充与缺陷

用户先反馈背景上下裁切、入口边框和箭头、资料卡背景与效果图不符；再次复核指出菜单最外圈缺白框、箭头多白色环、资料卡装饰仍不符；随后反馈头像圆形区域触碰资料卡边框，要求缩小并上下居中。另明确提出删除“我的小麦仓”页头，让下方元素上移。上述均属于本应用“我的”页，分别按缺陷 v1–v3 和补充设计获批后实施。

最终验收标准：背景顶部完整，竖向不足只裁底部；六个入口为各自渐变底、白色最外框和彩色内框，箭头为无白环的实心圆底和单层右箭头；资料卡为奶油渐变、白色外框与暖色内框，底部左右花草及姓名旁光芒可见；头像为 84dp 圆形区域，在资料卡内垂直居中且不触碰内框；“我的小麦仓”页头不显示，资料区与入口上移，同时保留安全留白、数据、点击与滚动规则。用户于 2026-10-16 明确确认主需求、全部补充及缺陷在 Pad 上测试通过。
