# 家长端“我的”菜单闪退修复

- 需求编号：20261029-parent-app-profile-menu-crash
- 日期：2026-10-29
- 应用范围：parent-app
- 提出人：用户
- 类型：缺陷
- 原始描述：当前分支的本地测试包，家长端的“我的”页面，点击任务库、分类管理等菜单，测试包会闪退。

## 目标与约束

修复菜单进入过程中数据加载失败导致的应用退出，能够显示失败原因并重试。重点覆盖任务库、分类管理，核对同页其他菜单的加载异常处理。

当前工作区有其他需求的未提交修改，必须保留。仅处理家长端，不调整其他应用功能，不在本流程直接变更数据库或共享仓库接口。数据库缺失能力应明确提示，后续由独立数据库流程补齐。

## 验收标准

1. 正常服务下能进入任务库和分类管理并显示真实数据，返回“我的”正常。
2. 断网、服务不可达、查询表不存在或响应解析失败时，页面停止加载并显示错误与重试入口，不闪退，不把请求失败显示成空列表。
3. 分类、模板及分类任务关联的并行加载互不连带取消；保留已加载内容，失败依赖恢复前禁止依赖该数据的写入操作。
4. 重试恢复正常数据，重复点击不产生重复订阅；页面退出正确取消加载。
5. 同页其他菜单在入口加载失败时保持应用运行并反馈错误；不扩展其业务能力。
6. 自动测试、构建通过后，经安装确认和用户人工验收。

## 依赖与范围

使用现有 AuthRepository、TaskTemplateRepository、CategoryRepository 等接口。共享实现仅作为调用链分析对象；不改变其他应用消费这些接口的行为。现有本地数据库基线不保证覆盖全部业务表与 RPC。
