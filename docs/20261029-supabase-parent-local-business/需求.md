# 家长端本地业务数据服务缺陷

- 日期：2026-10-29。
- 范围：独立 `supabase` 模块，仅本地 `lemon-kids-local` 中家长端依赖的业务结构和接口。
- 提出人：用户。
- 原始反馈：“没有闪退，但是目前所有数据都是加载失败的状态”；进一步确认：“我的各个菜单和首页任务都是失败，只有孩子列表是成功的”。

## 背景与目标

家长端闪退容错修复已安装，用户确认不再闪退，但业务尚不可用。本地容器运行健康，public 仅有 families、users、binding_codes、tasks 四张业务表，缺少分类、任务库、奖励、勋章、设备日志与任务用时等依赖。孩子列表已有核心用户表支持。首页同时加载分类、模板、关联与用时统计，不能把首页失败简单等同于 tasks 表缺失。

目标是补齐家长端核心本地业务服务，使首页任务及“我的”核心管理菜单可读取和执行既有操作。新业务没有记录时返回真实空列表，保留现有家庭、账号、任务数据；不自动复制线上数据，不伪造历史数据。

## 约束与依赖

仅修改本地数据库模块；不修改五个客户端源码、不部署线上服务。依赖现有核心基线与家长注册建家庭迁移。历史分类脚本含清空任务和积分语句，不能整份执行。外部腾讯云 SCF 诊断服务不因补数据库自动就绪，应单独核实并报告可用边界。

## 验收标准

- 核心表/字段/RPC 与当前家长端调用匹配；当前账号可读取孩子和已有基础任务。
- 分类、任务库、分类关联可读写；首页任务创建、编辑、取消/恢复/清理规则保持现有语义。
- 用时汇总和明细、奖励目录及图片、勋章进度、设备日志查询不因缺失本地结构失败；空库无记录时返回合法空结果。
- 两家庭、家长、孩子、匿名权限验证通过；保留原账号、家庭、任务，通用服务与线上环境不受影响。
- 自动测试通过后等待用户确认应用到现有本地库；应用后等待设备人工验收，不提前标记完成或推送。
