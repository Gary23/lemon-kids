# 需求：柠檬任务显示真实孩子姓名

- 需求编号/目录：`20261004-kid-task-app-child-name-copy`
- 日期：2026-10-04
- 应用范围：`kid-task-app`
- 提出人：用户
- 原始需求描述：「新增一单需求，柠檬任务app中所有“小当家”文案的地方都改为真实的孩子姓名」

## 背景与目标

柠檬任务当前有两处实际界面可能显示“小当家”：固定侧栏的孩子摘要使用写死文案；“我的成长”页在姓名为空时使用该文案兜底。希望两处都显示当前登录孩子账号的姓名，与资料中的 `users.name` 一致。

## 范围、约束与依赖

- 仅调整柠檬任务应用运行时界面的姓名展示，不将设计稿中的示例姓名写死到应用。
- 当前孩子身份以已登录的任务绑定码会话为准；姓名使用该会话对应 `users.name`，不读取家庭中其他孩子的姓名。
- 姓名修改成功后，固定侧栏与成长页应显示新姓名；切换账号后应显示新会话对应姓名。
- 资料加载中或姓名为空时，不继续显示“小当家”，也不伪造姓名；具体占位文案由设计明确。
- 不改变姓名编辑入口、账户/数据库结构、其他应用界面或任务与奖励功能。

## 跨模块影响及其他应用

读取既有 `:shared` 的 `AuthRepository.observeCurrentUser()` / `AuthViewModel` 用户状态及 `users.name` 字段；不修改共享模块、Supabase 或家长端。`shared/docs/UI-SPEC.md` 的“小当家”属于早期历史示意，不是当前任务端运行时文案，本流程不改该历史参考稿。

## 可验证的验收标准

1. 登录姓名非空的孩子账号后，固定侧栏孩子摘要与“我的成长”页均显示该孩子的真实 `users.name`，运行时不再出现“小当家”。
2. 在“我的成长”修改姓名并保存成功后，两处显示随当前用户资料更新；切换到其他孩子账号后不会保留前一孩子姓名。
3. 姓名仍未取得或为空时，两处显示明确的非姓名占位，不显示“小当家”，不显示错误孩子的姓名。
4. 自动测试通过后取得安装确认，设备安装后等待用户人工测试通过，才可提交推送并标记完成。
