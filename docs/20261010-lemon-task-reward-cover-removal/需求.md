# 需求：奖励取消预设封面

- 需求编号/目录：`20261010-lemon-task-reward-cover-removal`
- 日期：2026-10-10
- 应用范围：`parent-app` 与 `kid-task-app`。用户明确要求合并为一个需求，统一设计、执行和验收。
- 提出人：用户
- 原始需求描述：
  > 从product创建新的柠檬任务开发分支
  > 1. 家长端创建奖励的时候删除预设封面，编辑的时候也删除，直接不要预设封面了
  > 2. 柠檬任务端，奖励页面不再展示预设封面，图片没加载出来的后展示一个浅灰色背景就可以
  > 合并为一个需求

## 背景与目标

家长端新增和编辑奖励时提供六种预设封面；奖励列表及柠檬任务奖励页也会在无上传图片或加载失败时展示预设图片或礼物图标。统一移除这些可见的预设封面；柠檬任务端图片未显示时展示浅灰色背景。

## 范围与约束

- 家长端新增、编辑奖励时不再出现预设封面选项，也无需选择封面即可保存。原有上传图片的选择、预览、替换、移除和保存流程继续可用。
- 家长端奖励列表和编辑预览不再显示预设图标；列表无图或图片未加载成功时显示浅灰色图片区，失败仍可重试。
- 柠檬任务奖励页的大心愿、小心愿只显示家长上传图片；无图、签名等待或失败、首次加载中、下载或解码失败时，图片区显示浅灰色背景。
- 保持现有卡片尺寸、裁切、圆角、角标、文字、积分和兑换操作。同一图片在刷新时尽量保持已加载画面；图片路径更换或移除时立即舍弃旧图。
- 数据库 `cover_key` 目前非空且有限定值；保留其兼容字段，新奖励写现有默认值，编辑旧奖励保留原值，不做迁移。

## 非目标与依赖影响

- 不调整奖励价格、类型、大心愿、启停、兑换或兑换历史。
- `shared` 模型、仓库和 Supabase 字段、存储权限均不变；两个应用共用现有 `Reward.imagePath`。家长端仍写兼容的 `cover_key`，柠檬任务端不再据此选择可见封面。

## 验收标准

1. 家长端新增、编辑均不出现预设封面选项；无上传图也能保存。上传图可预览、保存、替换、移除，失败可重试。
2. 家长端奖励列表无图或图片未加载成功时不显示旧预设图标，显示浅灰色图片区；编辑器也不显示预设图标或相关文案。
3. 柠檬任务端大、小心愿有可加载图片时显示上传图；无可显示图片时统一为浅灰色，不显示预设图或礼物图标。
4. 刷新、滚动和页面恢复不使同路径的已加载图片闪回占位；家长替换或移除图片后刷新不会沿用旧图。卡片信息与兑换行为不受影响。
5. 自动测试通过后分别取得家长端和柠檬任务端设备安装确认；安装后等待两个应用的人工测试结论，均通过前不推送或标记完成。
