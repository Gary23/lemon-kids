# 设计：未通过朗读诊断记录

## 问题分析与目标

腾讯 SDK 的最终结果回到 `LemonLiteracyApp.kt` 的 `onFinish`，客户端按 `PronAccuracy`（低于 60 分）及缺分数时的 `MatchTag` 判定标红。现有 `evaluate-reading` 云函数只准备参考文本和凭证，不接收最终评测结果，因此无法从 SCF 日志回看标红样本。一次词组含多个词，每个词都是独立回调。

目标是让后台能按一次失败的评测回调查看目标与腾讯逐项结果，分析漏判、误判和映射问题，同时保持孩子当前反馈流程。

## 触发与数据流程

1. 客户端只在当前有效 `onFinish` 回调完成解析后检查 `wrongCharacterIndexes`。非空即产生一次 `attemptId`（随机 UUID）并异步上报；空集不上传。取消后的迟到回包沿用现有 `evaluationAttemptId` 过滤。主字部分重复读对、部分标红时也上传一次。
2. 上报与界面结果处理分离，使用现有 `ReadingEvaluationViewModel` 的鉴权请求能力在后台发起；给诊断请求设置较短超时，不自动重试，避免阻塞录音、星级和下一词。上报失败只写本机有限日志，不能打印回调正文或凭证。
3. 新增 `record_failed_reading_diagnostic` 动作。云函数先校验 Supabase JWT，再以 `loadTarget` 核对当前孩子、内容来源、任务 ID、目标类型、指定词／句及 `itemOrder`。服务端以核对后的教学文本作为日志中的目标文本，不信任客户端自报目标文字。
4. 请求传 `attemptId`、目标定位字段、`wrongCharacterIndexes`、`failureReason`、`textMode`、`evaluationTextLength`、从腾讯回调白名单提取的逐项结果。客户端对白名单字段设置条数、字符串长度和总体大小上限；服务端再次校验、裁剪或拒绝异常载荷。
5. 服务端以单行 JSON 输出结构化日志：固定事件名 `READING_EVAL_FAILED`，并包含服务端时间、稳定的孩子 ID 哈希、`attemptId`、已核对目标及顺序、标红位置、判定版本、`failureReason`、`textMode`、腾讯逐项 `Word`／`PronAccuracy`／`MatchTag` 及存在时的其他确定有助排查的评分字段。哈希只在服务端根据已鉴权孩子 ID 生成，供家长端受控查询接口按孩子过滤。日志不包含登录 Token、STS 凭证、录音、完整原始回调或未校验任意文本。接口只返回 `{status:"recorded"}`。
6. `failureReason` 至少区分 `low_pron_accuracy`、`match_tag_fallback`、`missing_words`、`unreturned_expected_characters` 和 `mapping_uncertain`。一个回调可同时有多个原因；此字段仅表示客户端为什么标红，不宣称孩子实际读错。

## 文件与兼容性影响

- `kid-literacy-app/src/main/java/com/lemonkids/kidliteracy/LemonLiteracyApp.kt`：在有效回调中构造诊断摘要并触发上报；解析时保留导致标红的原因。
- `kid-literacy-app/src/main/java/com/lemonkids/kidliteracy/feature/reading/ReadingEvaluationViewModel.kt`：新增不影响朗读主流程的上报请求。
- `cloud-functions/evaluate-reading/index.js`：新增鉴权动作、输入约束、目标核对和结构化日志。`server.js` 无需新增路由。
- 新版客户端面对未部署新动作的旧云函数只会记录诊断失败；原评测流程保持兼容。先部署云函数，再安装新版应用。
- 无 Supabase 迁移；诊断数据仅存在于 SCF 日志，查询与保留受腾讯云日志配置控制。
- 依赖另一个应用范围的[家长端日志查询设计](../20261019-parent-app-reading-diagnostic-logs/设计.md)。本流程负责输出可被 CLS 按事件名和孩子哈希检索的字段；CLS 日志投递、索引与家长查询接口由家长端流程记录并独立验收。

## 风险、验证与回滚

- 腾讯返回格式可能有嵌套或未知字段。仅抽取已知字段，并对缺失值显式标记；不能把参考字 `Word` 解释为孩子实际发音。
- 上传失败会遗漏样本。首版采用一次尽力上报，避免重试造成重复日志；可用 `attemptId` 关联客户端和服务端排障。
- 日志含教学词句及评测结果，应只在受控 SCF 日志查看，按现有日志权限与保留配置管理。匿名关联标识不输出孩子姓名或原始孩子 ID。
- 自动测试覆盖解析、触发、输入校验、越权、白名单日志及上报失败旁路；Android 构建和云函数测试通过后，取得安装确认再做实机验证。实机检查日志中有且仅有对应未通过回调的一条事件。
- 回滚客户端上报调用与云函数新动作即可恢复原流程；旧客户端不受影响。云函数源码改动后生成新 ZIP，并以 `unzip -l` 核验根目录及 README 包名。

## 待用户确认的设计决策

- “未通过”按当前客户端解析后存在标红汉字定义；主字多次连读中只要部分字标红，也记录该次回调。
- 首版仅写 SCF 结构化日志，不建数据库表，也不上传录音；记录腾讯逐项评分与客户端判定原因，不能还原实际语音。
- 每个有效失败回调尽力上报一次、不重试；日志缺失不影响孩子继续练习。
- 先发布云函数，再安装新版 Pad 应用；自动测试通过后另行取得安装确认。
