# 字词句未通过时上报朗读诊断记录

- 需求编号/目录：`20261019-kid-literacy-app-failed-reading-diagnostics`
- 日期：2026-10-19
- 应用范围：`kid-literacy-app`；依赖 `cloud-functions/evaluate-reading`
- 提出人：用户

## 原始需求

> 那新增一个需求，在字词句未通过后就上传一条诊断记录

## 背景与目标

孩子读词句时，存在读对却被标红、读错却被判通过的反馈。现有腾讯评测回调只在 Pad 上解析，云函数日志缺少逐字评分和标红位置。目标是在每次字、词、句评测有未通过字时，向云函数上报一条可检索的诊断记录，供排查评测返回值与客户端判定之间的差异。

## 范围、约束与依赖

- 仅覆盖柠檬认字应用的朗读评测；云函数接口变更归入本应用流程。其他应用不变。
- 上传对象是一次有效的腾讯评测完成回调，不是整组词的汇总。每个词单独评测、单独记录；主字重复朗读也按一次回调记录。
- 记录必要的目标、客户端判定、腾讯返回的逐项诊断字段；不上传录音、临时凭证、登录 Token 或完整原始回调。
- 云函数按当前登录孩子鉴权并核对教学目标，在 SCF 日志输出单行结构化记录，供后台筛选；本需求不新建数据库表。
- 上报属于诊断旁路，失败不能改变星级、标红、进度或阻塞孩子继续朗读。日志平台的保存期限取决于腾讯云配置。
- 修改 SCF 源码后须生成并核验新的部署 ZIP，更新云函数 README。开发、自动测试、设备安装、人工测试按 [`docs/README.md`](../README.md) 门禁执行。
- 家长端查看记录属于独立的 [`parent-app` 需求](../20261019-parent-app-reading-diagnostic-logs/需求.md)；本流程只负责产生可按孩子安全筛选的日志。

## 非目标

- 不调整腾讯评测参数、60 分阈值、字词句通过规则或现有界面。
- 不从评分结果推断孩子实际读出的文字；不把腾讯参考文字当成语音转写。
- 不记录已通过的评测、取消录音、连接错误或未收到有效最终回调的请求。

## 验收标准

1. 字、词、句各完成一次有效评测回调，只要解析后存在未通过汉字，就向云函数发起一次诊断上报；通过的回调不发。词组逐词评测分别处理。
2. 记录能按固定事件名筛选，并包含时间、匿名关联标识、目标类型及文本、来源及顺序、客户端标红位置与判定规则版本、腾讯逐项 `Word`、`PronAccuracy`、`MatchTag` 等可用诊断字段，以及缺失逐项结果等原因标记。
3. 云函数验证登录态、目标归属、文本和索引范围，并限制字段与载荷大小；日志不出现录音、密钥、Token 或完整未经筛选的腾讯回调。
4. 网络失败或接口拒绝时朗读反馈与进度照常完成，客户端只留有限的本地错误提示，不向孩子展示诊断错误。
5. 自动测试覆盖字词句触发、不触发、缺失逐项结果、越权和畸形载荷，以及诊断上报失败不影响朗读；实机人工测试能在 SCF 日志按事件名找到一条未通过样本。

## 已验收的补充（2026-10-19）

新发生的未通过朗读诊断同时上报经敏感字段剔除、JSON 格式及大小校验的腾讯评测原文和保存状态，保留原字段名、层级和值，供家长端对照；旧记录无法补齐。无效、超限或删减需明确标记，不上传录音、Token 或密钥，失败上报仍不影响朗读。家长端展示由其独立[补充流程](../20261019-parent-app-reading-diagnostic-logs/需求.md)验收。
