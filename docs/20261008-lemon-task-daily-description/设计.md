# 设计：每日任务描述与首页提示调整

## 问题与目标

`task_templates.description` 当前通过 `create_tasks_from_selection` 复制到每日 `tasks.description`。家长端任务库可编辑模板描述；具体任务编辑页也能编辑描述，但保存重复日程时可能批量覆盖该系列未来任务，不能稳定地按天发布内容。孩子端首页待完成列表另有一行“长按任务卡可调整顺序”，拖动时会切换为“拖到想放的位置，再松手 ✨”。本次统一处理这两处体验。

## 家长端交互与数据流程

1. 在任务库新建/编辑弹窗移除描述输入，列表不显示模板描述。旧模板描述保留在数据库，避免无提示删除历史数据；新创建的任务实例不再从模板读取它。
2. 按用户后续补充，家长端今日列表与日历所选日期任务列表均通过笔图标进入现有编辑页；点击列表项不再打开描述弹窗。已有任务的编辑页预填该实例的“当天任务描述”多行输入，新建任务流程不显示描述输入，因为新建可能覆盖多个日期。保存时去首尾空白，清空按空字符串保存；列表管理模式和删除入口保持原有行为。
3. 描述专用保存只按 `tasks.id` 更新单条任务实例。允许家长编辑家庭内、未取消、状态为待完成且日期为今天或未来的任务；过去及已完成的任务可查看历史描述，但输入只读。日期按 `Asia/Shanghai` 判断。保存期间禁用重复提交，失败时保留编辑页草稿并显示错误。
4. 通用任务属性更新不写入 `description`，重复日程批量更新也不覆盖已发布的每日内容。编辑页将属性更新与描述单条 RPC 编排，两个写入步骤都成功后才返回列表；若部分成功则留在页面并明确提示。`shared` 增加单条描述更新接口；Supabase 增加受控 RPC，校验家长身份、家庭、任务状态和日期后更新一条记录。成功后触发任务刷新，日历还需重载当前月份及选中日期，避免缓存显示旧描述。
5. 新 SQL 迁移替换当前同签名 `create_tasks_from_selection`，把新插入任务的描述设为空字符串，保持原有日期、去重、分类、积分、成长领域和权限逻辑。重复创建时的冲突处理不得覆盖已经发布的描述；已有任务实例及模板记录不批量清空。

## 孩子端交互

在 `kid-task-app/.../feature/home/PendingTaskDragColumn.kt` 删除非空任务列表标题下的提示行，包括常态和拖动中的文案及其占位。保留空列表提示、卡片无障碍描述、长按手势、拖动动画、排序持久化、朗读与打卡。孩子端现有卡片和朗读继续消费 `tasks.description`，显示所点日期实例的内容。

后续补充使今日待完成及过期卡片的分类标签与左侧竖条直接共用同一个不透明分类色。2026-10-09 通过 Stitch MCP 读取 `Kids Lemon Task App UI` 项目（`10281478774604750732`）的 `Lemon Tasks (柠檬任务)` 设计系统（`assets/a435997bbab54ab689399680d1e6f86d`）和“平板横版：今日任务（灵动微交互版）”屏幕（`3e1690a2608d4b6cb7ffdbf325d6ac99`）；依据设计系统 `designMd` 和屏幕截图选取色系，屏幕 HTML 链接跳转登录页而未读取。色卡原有亮色不足十种，因此用同风格扩展色补足；Pad 实机反馈首版偏深后，整体调浅为最终十色。这些最终色值是基于色卡的调整色，并非 Stitch 原色，见[最终色块预览](柠檬任务-调浅十色预览.svg)：

对同一天可见分类按稳定键排序，优先选择键的哈希槽，冲突时选下一个空槽；最多十个可见分类不撞色，任务排序不改变分配。超过十类可能复用颜色，分类集合增删可能使部分已有分类换色。颜色未持久化，完成状态样式和任务数据不受影响。

## 风险与回滚

- 旧家长端仍可能通过通用任务编辑批量写入系列描述；新版移除此入口。迁移会停止模板描述进入新日程；旧版本应同步升级。若数据库迁移未部署，新版保存会显示错误并保留草稿。
- 回滚客户端或数据库函数不会删除已经写入的任务实例描述。孩子端提示文字可恢复该视图分支；配色可回退颜色常量，若回退分类分配算法，需同步调整同屏唯一色验收标准。

## 验收与测试计划

- 自动测试覆盖单实例更新、跨日期/孩子隔离、重复日程不覆盖、权限与状态日期校验、新任务默认空描述、旧内容保留、失败回显、日历刷新及拖动功能保留；执行相关单元测试、两个 App 的 Debug 构建和 SQL 静态检查。十色唯一性、映射稳定性和拖动界面测试编译另行验证。
- 自动测试通过后分别请求家长端与任务端的安装确认；安装后由用户实际检查家长端首页和日历、任务端描述展示与朗读、拖动及空列表。人工测试确认后同步长期文档，再提交推送并标记完成。

## 待确认的设计决策

- 每次只编辑所点任务实例的描述；过去或已完成任务的内容保留为只读历史；通过首页和日历的笔图标进入编辑页。
- 移除拖动提示在常态与拖动中出现的可见文字，保留无障碍描述。
- 采用最终调浅十色，标签与竖条同色，同屏最多十类不撞色。
