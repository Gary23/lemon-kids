# 需求：番茄钟体验优化

- 日期：2026-11-11
- 提出人：用户
- 应用范围：`kid-task-app`（柠檬任务）
- 编号：20261111-kid-task-app-pomodoro-optimization
- 关联：上一轮番茄钟需求已完成，本次作为独立新增需求。

## 原始需求

> 1. 番茄钟弹出层，今日收获几个番茄的右边一直显示"番茄数量更新失败，点击重试"
> 2. 番茄钟的响铃和震动停止按钮太难看了，文案就改成"停止响铃"，大小就和开始专属与结束本轮差不多就可以，并且横向并排不要去占据倒计时表盘的位置，停止按钮的提示语也删除
> 3. 番茄钟增加一个暂定按钮，任务过程和休息过程都可以暂停，所有的按钮全部并排
> 4. 点击番茄钟弹出层右上角的关闭按钮，如果当前轮没有结束，不论是暂停还是正在倒计时，都关闭大弹出层，弹出一个小的弹出层在app所有页面的右上角浮动展示一个小的弹出层，只展示倒计时的过程（倒计时环形进度条和时间，颜色和原来一致），其他要素一虑不展示，点击这个小的弹出层的交互效果就是重新打开大弹出层，如果在小弹出层倒计时结束就开始响铃震动，点击后打开大弹出层才能停止响铃震动

## 用户修订（2026-11-11 22:48）

> 不，60秒超时是兜底的，要保留，说白了小的弹出层点击后就是弹出原来大的弹出层，除此之后小的弹出层没有任何点击交互事件。
> 另外在增加一条，任务到休息之间也不要自动切换，还是需要手动点击按钮才能进入休息

## 目标与边界

- 修复数量持续失败，不以隐藏真实错误代替修复。
- “暂定”按“暂停”理解；“开始专属”按现有“开始专注”理解。
- 计时控制按钮同排，停止提醒不再挤占表盘。
- 专注、休息均支持暂停/继续；收起不结束也不暂停当前轮。
- 小窗为应用内全局浮层，不申请系统悬浮窗权限、不覆盖其他 App。
- 保留专注完成计一个番茄、下一轮手动开始和退出 App 不恢复当前轮的规则；专注结束后等待手动开始休息。
- 保留提醒 60 秒自动停止兜底；小窗唯一点击行为为打开原有大窗，不提供停止提醒、暂停等其他交互。
- 其他应用不在范围内。共享仓库与数据库如需修改，仅限本应用番茄记录的依赖链，明确兼容旧客户端。

## 验收标准

1. 正常联网且服务可用时能读取、更新数量，成功后清除错误；真实失败可重试，不丢记录、不重复计数。
2. “停止响铃”同时停止声音和震动；与暂停/继续、结束本轮等计时按钮同排、同等高度；删除原停止提醒说明区域。
3. 专注与休息暂停后数字和圆环冻结，继续后从剩余时间恢复；暂停不计入有效专注时长、不产生番茄。
4. 未结束轮次关闭大窗后右上角显示小窗，跨页面保留；仅显示环与时间，颜色与大窗一致，点击恢复大窗且不停止提醒。
5. 小窗到点自动响铃震动，但不自动打开大窗；提醒最多持续 60 秒。专注结束计数一次并停在 00:00 等待开始休息，小窗保持可打开；大窗点击“开始休息”才启动完整休息时长。打开大窗或停止响铃均不自动开始休息；休息结束保留 00:00 小窗供打开操作。
6. 未开始或已结束且无待处理提醒时关闭大窗，不产生小窗；结束本轮后移除小窗。
7. 自动测试通过后另行确认安装；人工验收通过前不推送或标记完成。
