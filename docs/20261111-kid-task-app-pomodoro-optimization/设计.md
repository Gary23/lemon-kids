# 设计：番茄钟体验优化

## 现状与问题分析

- 数量失败文案来自协调器的通用异常映射，并非静态常驻文本。目前未获得运行时原始错误，不能断言具体根因。执行时检查查询范围、RPC 参数与返回解码、鉴权及待上传记录校验；保存脱敏诊断后针对根因修复，不吞掉异常。
- 大窗关闭当前会停止提醒；主导航收到提醒会自动打开大窗。这两处均与新小窗交互冲突。
- 当前会话只有阶段与截止时间，没有暂停状态。
- 共享仓库要求完成时间严格等于开始时间加专注时长；引入暂停后实际经过时间会变长，必须核对客户端及数据库校验，不能只改 UI。
- 用户已明确保留 60 秒自动停止兜底；小窗仅负责打开原有大窗，不承载其他操作。本次不额外移除既有通知停止动作。
- 当前专注结束自动进入休息，需新增“等待开始休息”阶段，由大窗按钮手动启动休息。

## 方案

### 数量同步

分离正在加载、读取失败、上传失败和待同步状态；成功清除对应错误，保留缓存与未上传记录。重试复用现有幂等轮次 ID。检查首页、日历与弹层显示一致性。若发现需要数据库修复，纳入本应用依赖并记录部署与回滚要求；不得以伪造 0 或隐藏错误充当修复。

### 大窗布局

- 保留现有主体表盘及颜色，移除独立提醒条与停止按钮提示语。
- 表盘下方使用独立单行操作区，按钮高度约 48dp、统一圆角与间距。
- 准备态：开始专注；专注/休息态：暂停（暂停后为继续）、结束本轮；等待开始休息态：开始休息、结束本轮；休息结束等待态：下一轮。有提醒时在同一排追加“停止响铃”。
- “停止响铃”仍一次停止声音和震动，不改变计时阶段。
- 同时可用的计时按钮全部并排；窄屏采用紧凑间距及必要的横向滚动，不挤入表盘。标题区的设置与关闭仍在标题区。

### 暂停规则

- 专注和休息均可暂停，冻结剩余毫秒与圆环，不推进阶段、不产生到点提醒。
- 点击暂停先结算到当前时间，防止临界点遗漏完成事件；若已到专注终点则进入等待开始休息，不启动或暂停尚未开始的休息。
- 继续根据暂停剩余时间重建截止时间；休息截止时间仅在手动开始休息时建立，休息暂停不改变已完成专注。
- 暂停不等于停止响铃，已有提醒仍需点“停止响铃”。暂停时禁止修改本轮时长，但可结束本轮。
- 会话依然仅存内存；退出/销毁释放资源，重新启动不恢复。
- 记录真实开始与完成时间，暂停不计有效专注时长。必要时放宽仓库及数据库“经过时长必须等于专注时长”为“不短于专注时长”，维持允许时长、身份、未来时间与 sessionId 幂等校验，兼容旧无暂停记录。数据库实际约束检查后实施；若需更大模型改动，先补充设计确认，不伪造开始时间规避校验。

### 手动开始休息

- 专注到点仅记录一次完成并触发提醒，进入“等待开始休息”，剩余时间为 00:00，保留专注结束的红色空环。
- 等待期间不消耗休息时长，也不会因提醒停止、超时、打开大窗或切换页面自动开始休息。
- 大窗点击“开始休息”后从完整配置时长启动休息，切换海洋蓝圆环，并释放旧专注结束提醒；重复点击不得重置休息截止时间。
- 等待开始休息仍属于未结束轮次，关闭大窗进入小窗，即使提醒已超时停止也保留入口；可在大窗结束本轮，已获得番茄不撤销。

### 应用内全局小窗

- 将番茄钟展示状态放在覆盖应用内各页面的共同宿主，避免导航或进入设置后丢失；计时仍由唯一协调器持有。
- 展示状态分为隐藏、大窗、小窗；关闭未结束轮次的大窗切到小窗，暂停也相同。关闭本身不停止声音/震动。
- 小窗固定在安全区域右上角，建议 96dp 左右的轻量圆角容器。无蒙层，不阻断其他页面操作，仅自身区域响应点击。
- 仅绘制圆环和 mm:ss，无标题、图标、暂停标记、关闭按钮和说明；保留无障碍语义但不额外显示文字。
- 与大窗共用进度/颜色规则：专注绿/金黄/红，休息海洋蓝；暂停冻结，休息结束为蓝色 00:00。
- 小窗唯一点击事件为打开原有大窗，不重启计时、不停止提醒、不启动休息；不提供内部按钮、长按、双击或拖动等额外交互；大、小窗不同时出现。
- 小窗到点不自动展开，专注结束响铃并等待手动开始休息，休息结束保留小窗与操作入口；60 秒停止提醒不自动隐藏小窗。
- 未开始或等待下一轮且已无提醒时，关闭大窗直接隐藏。结束本轮、退出登录、退出应用释放对应展示和运行状态。

### 提醒行为

保留每次提醒 60 秒自动停止的兜底。关闭大窗、点击小窗打开大窗均不停止提醒或重置超时；在大窗点击“停止响铃”同时停止声音和震动。开始休息、结束本轮、下一轮以及退出应用释放旧提醒资源。本次不额外改变既有通知停止动作；小窗本身不提供任何停止入口。

## 测试、风险与回滚

- 自动测试覆盖双阶段暂停/继续、重复点击、边界到点、跨日完成归属、暂停不计数、休息结束等待、同步失败重试和无重复上传。
- 验证展示状态转换、颜色边界、跨路由保持、关闭不停止提醒、小窗唯一点击打开大窗、到点不自动展开、60 秒自动停止。
- 验证专注结束仅计数一次且等待手动休息，等待不消耗休息时长，停止提醒或超时不启动休息，重复开始休息不重置计时，等待态关闭仍显示小窗。
- 构建 APK 并跑任务端/共享模块单元测试；取得安装确认后实机验收全部页面、真实声音震动、横竖屏及后台/退出行为。
- 风险：暂停后记录被旧校验拒绝、页面切换导致会话释放、提醒资源释放遗漏、窄屏按钮溢出。分别通过兼容校验、顶层生命周期、明确提醒决策与设备布局验收处理。
- 回滚：回退本需求代码恢复旧行为；数据库如仅放宽约束，优先保持兼容，收紧前检查已存在暂停记录，避免直接破坏历史数据。
