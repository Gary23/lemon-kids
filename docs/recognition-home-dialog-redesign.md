# 认字首页合并与朗读预取改造设计

## 目标

将独立“认字页”合并进首页：首页先展示当天待认识字（最多 8 个），再展示已认识字（最多 24 个）。点击单个字后打开一个占屏约 90% 的学习弹层，在同一处查看并练习字、词、句。

消除“开始”按钮先置灰等待 `prepare_evaluation` 的体验问题：主字不再请求该接口；词、句在打开弹层时静默预取，评测开始时直接复用缓存。

## 已确认的技术决策

1. 主字评测使用腾讯 `TEXT_MODE=0`。参考文本可由客户端安全地构造为 `displayText.repeat(剩余朗读次数)`，不依赖音素资产，也不调用 `prepare_evaluation`。
2. 词、句必须继续由服务端调用 `prepare_evaluation`。服务端会校验任务归属、查询已就绪的音素资产并生成 `TEXT_MODE=1` 的 `wordList`；客户端不得退化为本地 `TEXT_MODE=0`。
3. 评测准备缓存只保存在 `ReadingEvaluationViewModel` 内存中，不落盘。缓存绑定北京时间日期、孩子 ID 和首页数据批次；跨零点、切换孩子、首页重新加载或任务完成状态变更时清空。
4. 首页只预热腾讯临时凭证；主字因本地构造而无需预取服务端。打开单字学习弹层后，按受控并发（最多 3 个）预取该字全部词、句。
5. 同一时刻只允许一个项目录音或等待腾讯结果，其余项目的开始按钮不可用，以保护唯一的录音/评测 SDK 实例。

## 交互与数据流

```text
进入首页
  ├─ 查询当天待认识任务与已认识字，待认识在前
  └─ 静默领取腾讯临时凭证

点击单个字
  ├─ 打开 90% 屏幕学习弹层：字、词、句纵向排列
  ├─ 主字：开始时直接构造参考文本并录音
  └─ 词/句：弹层打开即受控并发 prepare_evaluation，写入当天内存缓存

评测完成
  ├─ 更新当天本地星星/错字/点读状态
  ├─ 主字下一次按剩余次数重新本地构造参考文本
  └─ 待认识字所有项目完成时提交原有收录流程，并失效该字缓存
```

## 实施清单

- [x] 1. 首页排序改为待认识在前，字格支持直接点击单字。
- [x] 2. 删除独立 `LEARN` 页面入口，首页直接打开单字学习弹层。
- [x] 3. 增加当天内存评测准备缓存、词句受控预取和失效机制。
- [x] 4. 主字开始朗读改为本地构造评测参数，彻底移除其 `prepare_evaluation` 等待。
- [x] 5. 重构为 90% 屏幕统一学习弹层：字词句纵向、星星与开始按钮同列、支持滚动、展示当前朗读状态与动画，保留长按点读及错字样式。
- [x] 6. 编译验证并更新本文件实施状态。

## 非目标

- 不改动 `evaluate-reading` 云函数；词句的多音字评测仍沿用现有服务端保障。
- 不将当日缓存写入 SharedPreferences、数据库或文件；第二天绝不复用前一天数据。
