# 设计：柠檬认字“我的”入口页面尺寸校准

## 问题与依据

参考 [`逐页元素清单.md`](../../ui-design/kid-literacy-app/design-concepts/安卓UI开发资源/逐页元素清单.md) 和 A02–A07 效果图，画板为 1536×1024 px。此前“我的”页实机记录为约 1000×567 dp 的可用窗口，按可用高度估算，参考图 1 px 约对应 0.55 dp。实际实现须按安全区与实机截图微调，不能将整张页面按固定系数缩放。

目前五个独立页面使用通用 `GardenPageHeader`、`GardenPanel` 和接近全屏宽的列表或网格；标题吉祥物为 100dp、面板内边距 20dp，记录卡和字格由剩余宽度撑大。A02 的木框约 1120×723 px（约 616×398dp），A03 的单张卡约 443×251 px（约 244×138dp），A04 的工具栏约 1070×116 px（约 589×64dp），A05 记录卡约 1219×184 px（约 670×101dp），A06 记录卡约 1310×213 px（约 721×117dp）。这些参考宽度均明显小于当前接近 1000dp 的内容区，需对每页分别限制内容宽度并重排。

## 页面方案

| 入口 | 参考重点 | 拟调整的布局 |
| --- | --- | --- |
| 待认识（A02） | 页头、数量条、木框与约 154×148px 字格 | 标准 Pad 上使主网格约 616dp 宽、字格约 85×81dp，按可用宽度决定列数；数量条放到标题附近，避免通用全宽统计面板占高。 |
| 已认识（A03） | 紧凑页头、约 729×57dp 汇总条、三列约 244×138dp 卡 | 卡片主体与字格、日期、操作按钮按卡宽重排；三列仅在可容纳时使用，窄屏换列并滚动。 |
| 字库（A04） | 约 589×64dp 工具栏、约 572×375dp 筛选网格面板 | 工具栏与筛选区居中限宽，统计、更新和导出按钮按参考比例排布；保留实际导出范围、搜索和字格操作。 |
| 帮助过的内容（A05） | 标题右侧下载按钮、约 670×101dp 记录卡 | 记录列表限宽，卡内内容、类型、动作按钮按参考比例调整；长词句换行时卡片自行增高。 |
| 通过记录（A06） | 约 239×46dp 数量条、约 721×117dp 记录卡 | 统计及清空动作安排在页头下，记录卡限宽；真实时间、星级快照、撤销及删除均清晰可点。 |
| 智能添加识字（A07） | 弹窗外框、标题、输入与双操作按钮 | 对照 A07 校准弹窗可见宽高和主要元素，不改变表单字段及生成流程；键盘、大字体时允许内部滚动。 |

五页使用页面专用尺寸约束或少量共享的二级页布局参数。标准 Pad 上按参考比例缩小元素及间距；最小触控高度保持 48dp，字体不机械等比缩小。背景继续铺满安全区；页面内容居中，较窄窗口或放大字体时改列数、换行或滚动。A02–A07 中的示例汉字、数量和记录仅用于视觉定位，实际界面显示真实数据。

## 文件、交互和风险

- 预计修改 `kid-literacy-app/src/main/java/com/lemonkids/kidliteracy/LemonLiteracyApp.kt` 的五页与智能添加弹窗布局；必要时仅为这些页面扩展 `ui/components/GardenComponents.kt` 或 `GardenLayout.kt` 的参数，不连带改变首页、“我的”主页及学习弹层。
- 不修改 ViewModel、接口或存储；按钮回调、错误提示、空态与返回路径维持现行行为。
- 参考图比例为目标，但屏幕画幅、系统栏与字体渲染不同；以设备截图核对主要容器、首屏密度及可点击性，避免强制尺寸造成文字截断。
- 回滚仅需恢复界面布局文件，无数据迁移。
- 人工验收后核对并最小化更新 `kid-literacy-app/docs/UI-SPEC.md` 与 `kid-literacy-app/README.md` 中相关页面的长期描述。

## 验证方案

自动运行 `./gradlew :kid-literacy-app:assembleDebug :kid-literacy-app:lintDebug :kid-literacy-app:testDebugUnitTest`，并对新增的独立布局规则进行有实际判别力的验证。通过后单独取得安装确认，再在指定 Pad 上逐一进入六个菜单入口，对照 A02–A07，检查正常数据、空态、长内容与关键操作。用户人工确认前保持测试阶段，不推送或标记完成。

## 设计确认

- 状态：2026-10-19 用户明确批准本设计，并要求完成自动测试后安装到 Pad。
- 待确认的设计决策：将五个独立页面和“智能添加识字”弹窗一并纳入本轮尺寸校准；以 A02–A07 作为视觉基准，优先调整页面专用内容宽度、卡片尺寸及间距，同时保留触控和可读性下限。

## 人工测试期间批准的补充设计

用户于 2026-10-19 批准：`GardenPageHeader` 为已认识、待认识标题增加小字号数量后缀，数量来自当前列表；已认识页删除数量面板并替换副标题，待认识页删除数量条。帮助记录卡将图文与右侧操作区分开，页头下载及错误态重新加载按钮也靠右；弹窗最大宽度从 565dp 调至约 650dp，并保留安全区、键盘避让与滚动。涉及 `LemonLiteracyApp.kt` 和 `GardenComponents.kt`；不改数据源或按钮回调。验收以新文案、实时数量、右对齐及窄窗口操作可达为准。

## 人工测试期间批准的输入缺陷设计

用户于 2026-10-19 批准：从输入框当前状态重新校验，允许半角/全角空格、换行、顿号及中英文逗号作为汉字分隔符；移除分隔符后去重，最多 12 字。无汉字、非法字符、超限分别提示，预览请求与保存使用同一归一化结果。涉及 `LemonLiteracyApp.kt`、`LiteracyCharacterInput.kt` 及对应单元测试；不修改请求协议、云函数或数据库。自动验证覆盖有效单字、多字、分隔符及错误输入，Pad 人工验收确认有效输入不再误报为空。回滚可恢复客户端输入处理，无数据迁移。
