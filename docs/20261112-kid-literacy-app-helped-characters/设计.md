# 设计：帮助记录单字展示

## 问题分析

当前 HelpedCharactersScreen 使用单列词句卡片，highlightedCharacterIndex 根据 requested_character 与 character_index 定位红字，兼容旧索引时只允许目标字在文本中唯一出现。删除和收录均以帮助记录 ID 为单位。已认识页面使用居中限宽 790dp（随布局倍率）、自适应最多三列网格、浅绿圆角卡片、字块、日期和紧凑按钮。

## 展示方案

1. 沿用现有红字定位规则，将可定位的 requestedCharacter 作为卡片唯一学习文本，不展示 targetText，也不再展示“词/句”类型说明。
2. 对无法定位目标字的历史记录不猜字、不显示原文，保留占位卡“目标字未知”及删除操作，禁用加入已认识；不修改原始数据。
3. 按可定位的目标字分组，同字不同记录仅显示一张卡片；保留关联记录 ID，不改写数据库内容。建议使用组内最新记录的日期，并按最新求助时间排序。无法定位的记录仍逐条占位，避免将未知字误合并。
4. 对齐已认识页面的内容限宽、列数断点、间距、浅绿卡片、白色边框、阴影、字块及日期样式。日期标签为“求助于”。标题保留“帮助过的内容”，副标题改为“这些字请求朗读过”；数量使用去重后的有效字数，未知记录另计。菜单副标题相应改为“我请求朗读过的字”。
5. 卡片只保留“删除”和“加入已认识”，使用已认识页面紧凑等宽按钮的尺寸、圆角、字号与配色体系（删除用蓝色，加入用绿色），窄屏/大字体保证文案可读。
6. 删除帮助过的内容页面的 TXT 下载入口及专用导出逻辑；不影响其他页面的下载功能。

## 交互和数据兼容

- 保持当前孩子作用域、加载、失败重试和删除状态。
- 用户已确认按钮作用范围：删除该字关联的全部帮助记录，加入已认识成功后也清理这些记录，避免同字再次出现。使用原始记录 ID 和当前孩子作用域，不按词句文本扩大删除范围，不影响其他孩子或其他目标字的记录。
- 加入已认识继续执行检查、内容预览/编辑、保存、清理帮助记录的流程；重复收录提示保持原状。按字清理需支持部分删除失败时保留未删除记录并重试，保存成功后重试清理不重复收录。编辑弹层仍可展示和编辑词句，本次只限制列表展示。
- 不改表结构、target_text、target_type、requested_character、character_index 等存储字段；不修改云函数接口。

## 涉及文件与模块

- kid-literacy-app/src/main/java/com/lemonkids/kidliteracy/LemonLiteracyApp.kt：菜单文案、帮助页面布局、卡片和展示规则调用。
- kid-literacy-app/src/main/java/com/lemonkids/kidliteracy/feature/help/：提取可单测的目标字定位与分组逻辑；保留现有数据模型和表字段，删除接口改为按记录 ID 集合清理。
- kid-literacy-app/src/test/：目标字定位与分组边界测试。
- 人工验收后同步 kid-literacy-app/README.md 的帮助内容说明、kid-literacy-app/docs/UI-SPEC.md 的帮助页面规范，以及 kid-literacy-app/docs/LEARNING-RULES.md 中帮助到已认识的清理范围。

## 测试与验收

自动测试覆盖：词与句提取目标字、合法索引、旧索引唯一出现回退、重复字歧义、空/非法目标字、不展示原文及不同记录同字去重、分组关联 ID 和最新日期/排序；运行应用单元测试及构建检查，Gradle 使用工作区 .gradle-system。
人工验收覆盖：横屏三列/窄屏换列、大字体、日期、两个按钮视觉及可用性、加载失败、删除、已认识提示、加入成功、保存后删除失败重试、同字去重及确认后的按钮作用范围、TXT 入口移除且其他页面下载不受影响。安装前须自动测试通过并取得安装许可。

## 风险与回滚

历史记录无定位信息时不可凭原文推断目标字；明确占位避免误收录。同字合并展示后须明确按钮作用范围，避免操作后同字再次出现或超出预期清理记录。展示不改写原始数据，可回退界面代码；已执行的用户删除操作不会因代码回退恢复。
