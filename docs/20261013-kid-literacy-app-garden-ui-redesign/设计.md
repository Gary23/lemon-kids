## 2. 现状与问题

| 现状 | 影响 | 本次方案 |
| --- | --- | --- |
| `AndroidManifest.xml` 锁定 `portrait` | 与所有横屏参考稿不匹配 | 改为 `sensorLandscape`，支持两个横屏方向 |
| 大部分 UI 集中在约 4400 行的 `LemonLiteracyApp.kt` | 页面和学习状态容易在换样式时相互影响 | 保留根层业务编排，逐步提取本应用的主题、组件及页面展示层 |
| 单色底、较小字格、单列个人菜单、通栏导航 | 缺少场景与层次 | 固定场景背景、独立插画、两列菜单、居中胶囊导航 |
| 部分页头固定，列表局部滚动；添加弹层表单不完全纳入滚动 | 横屏、字体放大和键盘时操作可能被挤出 | 页头、工具栏、列表和末尾导航/操作纳入纵向滚动体系 |
| 普通练习行和录音行分开实现 | 换样式可能导致尺寸不一致 | 共用行结构，固定星位、文字、五点动画、按钮及提示槽 |
| 字库文档仍描述首次 100 字及加载更多，代码已使用本地缓存 | 按旧规范重构会改变现有数据体验 | 保留当前缓存行为，验收后更正文档 |
| 发音标注按每条资产保存，通过记录保存各项目星数 | 源图的整窗保存及统一五星容易误导 | 保留逐条保存和完整快照，视觉按参考重新排版 |

本方案已获批准；按下表范围执行代码改动。

## 3. 视觉系统

### 3.1 场景与层级

三层结构：固定无字场景背景 → 可滚动内容与奶油面板 → 独立弹窗遮罩。树、云、书架、桌面随背景裁切；吉祥物、标题标志、入口插画和花草作为独立装饰，不占用点击区域，也不参与无障碍朗读。

- 首页/学习弹窗：`a07-a10-recognition-garden.png`。
- 我的：`a01-profile-farm.png`。
- 待认识：`a02-pending-garden.png`。
- 已认识：`a03-recognized-garden.png`。
- 字库：`a04-library-shelves.png`。
- 帮助记录：`a05-helped-reading-corner.png`。
- 通过记录：`a06-passes-desktop.png`。

大标题为深蓝粗体，关键词用绿/珊瑚色强调；通过文字阴影或描边形成参考稿的白色轮廓。正文始终在较不透明的浅色面板内，避免花园纹理降低可读性。装饰被裁切可以接受，正文和动作被裁切不可接受。

### 3.2 颜色、形状与字体

| 语义 | 主色 | 配套浅底/使用方式 |
| --- | --- | --- |
| 正文 | `#061A39` | 主要文字、汉字 |
| 次级文字 | `#687D9F` | 描述、日期、输入提示 |
| 蓝色操作 | `#2E9DFF` | 查看、刷新、生成、保存、开始；配 `#EAF6FF` |
| 绿色操作 | `#31B541` | 收录、存库、通过、满星；配 `#EFFBE5` |
| 柠檬黄 | `#FFDA4C` | 统计、置顶、星星；配 `#FFF4CD`，按钮文字用深棕 |
| 珊瑚色 | `#FF6B70` | 待认识分组、录音、删除；配 `#FFF0EB` |
| 错读红 | `#BA1A1A` | 保留明确错读语义及足够对比，不能用于点读高亮 |
| 奶油白 | `#FFFDF4` | 主面板和字格 |

保留现有颜色符号兼容调用，逐步改为语义化使用。珊瑚录音/删除色与错读红分开；求助记录中的被求助字继续使用明确标红。

- 面板圆角 28–36 dp，卡片 20–28 dp，字格 16–22 dp，按钮胶囊形。
- 内容间距采用 8/12/16/24/32 dp 层级；面板 1–2 dp 浅描边、轻微向下阴影；按钮使用浅渐变和底部阴影表达立体感。
- 平板标题 36–44 sp、卡片标题 24–28 sp、操作 20–24 sp、正文 18–22 sp、说明 16–18 sp；紧凑窗口允许调整标题字号，仍遵守系统字体缩放。
- 列表/任务汉字默认 52–64 sp，主字练习 64–72 sp。词语继续 40 sp、句子 34 sp，字间距 1.5 sp，保持当前规范的练习可读性。
- 字格和练习主字使用完整 `MaShanZheng-Regular.ttf` 近似参考手写字形；UI 正文、编辑输入、数字拼音及练习词句使用系统中文字体，避免影响逐字高亮与长句换行。字体缺字时回退系统字体；保留 SIL OFL 许可证，禁止将仅含示例字符的子集字体用于正式内容。

## 4. 页面设计

### H01 认字首页：补齐设计

参考 A07–A10 的弹窗底层画面。顶部为柠檬标志、“柠檬认字”、带孩子姓名的鼓励文案、刷新胶囊及欢迎吉祥物；下方“识字任务”标题。

待认识分组置前，采用珊瑚浅底和花朵标签；已认识复习组采用绿色浅底和嫩芽标签。每组保留日期/学习阶段与既有组标题，六个字槽并排；少于六字时字格宽度不扩大。完成字变为绿色边框并带完成标记，不能仅靠颜色区分。组内不提前展示词句。

保持当前最多一组待认识加三组复习、北京日期分组、当日共享快照、三天复习和真实星数。点击字直接进入统一学习弹窗。刷新期间保留页面及字格，禁止重复刷新；继续采用既有加载/空状态链路，不在本次引入新的请求策略。保留返回顶部按钮，避免遮住字格和末尾导航。

底部导航收敛为约 320–420 dp 的居中胶囊，标签“首页”改为参考稿的“认字”，页面路由仍为 `HOME`。导航放在滚动内容末尾，短内容时通过最小内容高度保持靠近底部，长内容滑到末尾可见。

### A01 我的

顶部“我的小麦仓”；孩子头像、真实姓名和鼓励语组成信息卡，右侧独立累计识字数卡，欢迎吉祥物在外侧。头像使用真实 URL；无头像或加载失败时使用交付的儿童头像插画。累计数继续来自当前孩子本地字库缓存，未缓存时隐藏统计卡，信息卡自动占用可用空间，不显示示例 36。

菜单两列三行，顺序按参考稿：第一行“已认识的字 / 查看待认识的字”，第二行“字库 / 帮助过的内容”，第三行“通过记录 / 智能添加识字”。每张卡由独立插画、标题、说明和箭头组成，采用参考稿六种浅底配色。

“字库”说明改为“收集我的汉字”，修正现有“按拼音收集”与实际无拼音分类的差异。窄横屏或大字体时菜单改为单列，入口顺序不变。末尾显示双导航。

### A02 待认识的字

圆形返回、标题、副标题、真实待认识数量和欢迎吉祥物；木色边框包围奶油字格。标准平板六列、自适应减少列数，列表不限制为源图的四行，也不复制图中“12 个”与实际 24 格不一致的示例。

每次进入沿用全量待认识查询；点字继续打开当前的发音标注详情。全部加载且确实到末尾才显示“已显示全部待认识的字”。保留加载、空、失败重试。

### A03 已认识的字

绿色标题、阅读吉祥物与奖杯装饰，汇总条显示当前真实总数及“置顶后，从今天起重新学习 3 天”。固定三列卡片，每卡仅有主字、收录日期和蓝色查看/黄色置顶/绿色存库。

保留请求成功后即时置顶、返回云端时间、其他字相对顺序不变、失败不移动及并发保护；存库仍须确认。“查看”沿用发音标注弹窗。日期按当前数据处理，不复制示例日期。返回以左上圆形按钮为主；木路牌可作为底部返回的装饰形式，不覆盖卡片和动作。

### A04 字库

书架场景，蓝书吉祥物位于面板外侧。顶部统计条含本地字数、蓝色“更新字库”和绿色“导出字库”；其下为序号输入、导出规则提示、搜索及标准六列网格。

遵循当前 `LibraryViewModel`：进入只读当前孩子缓存；点击更新才以每批 100 条拉取全量并覆盖缓存，失败保留旧缓存；搜索仅过滤缓存；不新增“加载更多”。未缓存显示“本地暂无字库数据，请更新字库”；缓存为空与无搜索结果分开提示。

导出使用完整缓存顺序，不受搜索过滤影响。序号从 1 开始、包含首尾、结束序号必须大于开始序号；开始越界报错，结束超出时截到末尾。仍调用系统保存文件界面，不新增文件权限。数据更新、导出结果和输入错误放入面板内可滚动提示区域。

### A05 帮助过的内容

阅读角场景、标题、蓝书吉祥物和绿色“下载 TXT”。记录卡左侧使用声音气泡装饰，中央显示完整可换行词句及被求助字的标红位置，右侧为绿色“加入已认识”和珊瑚“删除”。源图声音图形不额外变为播放按钮，避免新增操作链路。

延续已认识检查、重复收录提示、编辑后收录、成功只删除本条记录、删除失败单独重试；无法定位目标字的旧记录保留展示与删除，收录按钮禁用并说明原因。长句时动作换至下方，不截掉正文。

### A06 通过记录

桌面场景，标题、真实条数和剪贴板装饰。卡片包含大主字、待认识学习/已认识复习分类、北京时间、通过前快照及黄色“撤销通过”。删除按钮和“清空全部”保留，并保留原确认弹窗。

快照按“字、每个词、每个句”展示真实 `earned/required` 和相应星位，可以多行。不得把所有记录统一画成五颗星或汇总成一个模糊评级。已撤销显示撤销时间，不能再次撤销。记录长内容增加卡片高度，列表可到底。

## 5. 弹窗设计

### A07 智能添加识字与帮助记录编辑

蓝天花草标题、奶油面板、独立欢迎吉祥物、圆形关闭。上部输入汉字，下部按目标字显示可编辑词/句卡及删除分组动作。

初始态以“生成内容”为主动作；生成预览后显示“重新生成内容 / 添加到待认识 / 添加到已认识”，未满足现有提交条件的动作禁用。保持一次去重后最多 12 字、目标字不可编辑、词句校验、冲突标记和任务保存规则。技术实现名从提示文案移至文档，产品内使用“自动生成学习内容”等说明。

帮助记录复用同一外壳，但目标字固定，底部仅“确认并添加到已认识”，不显示生成和两个目的地动作；已有内容优先和缺失时生成规则不变。提交中的关闭/禁用逻辑沿用现有行为。

整个表单和末尾动作可纵向滚动；桌面宽度足够时三动作并排，否则换行。键盘出现时缩小可用高度并将焦点字段带入视野，不嵌套两个无限高度滚动容器。

### A08 发音标注

绿色花草标题，左侧浅黄词语区、右侧浅蓝句子区；两栏各展示全部资产卡，而非仅示例一词一句。每卡具有只读原文、真实就绪/准备中/失败状态及逐字数字拼音输入。

保留每条 `PhoneticAsset` 的独立保存按钮、保存中的禁用和错误反馈。源稿整窗底部“保存发音标注”不采用：现有接口按资产保存，不在本次增加跨资产批量/原子保存。底部提供关闭，右上关闭始终可达。

两栏纳入同一纵向滚动内容；较短一栏不拉伸其输入行。可用内容宽度小于 720 dp 或字体放大导致输入不够宽时改为“词语 → 句子”纵向排列。`null` 拼音仍显示“腾讯不支持指定轻声”，不能改成可输入字段；状态和校验沿用原逻辑。

### A09/A10 统一朗读练习与结果

云朵/花草标题、欢迎吉祥物、真实主字标题和“长按汉字可听正确读音”；正文按字/词/句展示。待认识字三个分区，已认识复习只展示字/词，不能出现空句分区。

每行依次为：固定星位栏 → 可长按的内容栏 → 五点动画槽 → 操作按钮槽；下面固定提示槽。星数按既有 3/2/1 等目标展示，不采用源图示例的四/五颗星。

| 状态 | 外观与动作 | 几何规则 |
| --- | --- | --- |
| 未开始 | 浅蓝边框，蓝色开始 | 所有槽位已存在，提示留白 |
| 准备中 | 准备提示、当前项禁止重复启动 | 按钮槽宽度和文字栏不变 |
| 录音中 | 珊瑚边框、五点动画、读完 | 只改颜色/动画/文本 |
| 评测中 | 评测提示、当前项禁止重复提交 | 维持录音行几何 |
| 结果未达标/错误 | 当前错字标红，既有完成/开始/重试路径 | 错误提示使用预留槽 |
| 满星 | 绿色学习态与真实星数 | 当次状态更新立即透明隐藏动画/操作，保留尺寸且不可点击/聚焦 |

固定约束覆盖初始、录音、评测、错误和满星：统一行组件、统一 padding/边框占位/内容栏/提示栏尺寸，不因渲染不同组件改变位置。标准布局右侧沿用 172 dp 操作区、82 dp 按钮槽；同一窗口下在进入练习前确定尺寸。字体缩放需要更大槽位时统一按窗口及缩放重新计算，不能按当前状态计算。

长词句按内容及字体预先计算相同行高；标红和高亮不改变字重、字号或字间距。固定两行提示槽，冗长错误用简明文案及不改变行高的详情入口。窗口变化可重排，状态变化不得重排；稳定 key 保持录音和结果切换时的滚动位置。

保持单项录音互斥、权限处理、关闭时取消及释放 SDK、预取词句参数、点读整词整句和主字求助计数。点读为蓝色高亮；无在线音频保持米色/暖灰提示与 TTS 回退。底部绿色“通过”沿用家长确认、快照记录、补满和已完成禁用，纳入弹窗末尾滚动区域。

### 其他已有弹层

存库、家长通过、撤销、删除、清空、已认识提示、加载/更新及会话恢复都使用相同的浅色面板、圆角和按钮样式。不可关闭的会话恢复弹层继续具有最高覆盖优先级，不允许视觉重构改变其阻断规则；需要提交锁定的确认弹窗保持既有关闭约束。

## 6. 横屏、安全区与滚动

- 横屏方向采用 `sensorLandscape`。4:3、16:10、16:9 都以实际窗口 dp 排版，源图 1536×1024 或 1586×992 仅作为构图参考，不直接换算绝对坐标。
- 使用 `WindowInsets` 处理系统栏和挖孔；安全区内四周默认至少 24 dp。背景 `ContentScale.Crop` 固定不随内容滚动，主内容居中最大宽约 1200 dp。
- 待认识/字库：字格最小边长 88 dp、间距 12 dp，标准窗口最多六列；按面板内宽度计算 3–6 列，极小窗口继续减少列数以保护文字和触控。
- 首页每组最多六字及业务分组规则保持不变；标准宽度六个等宽槽，窄横屏换行仍使用同一格宽，不足一行不拉伸。
- 已认识继续固定三列。窄窗口时内部日期和动作改为纵向排列，按钮仍至少 48 dp；不能因为普通状态变成加载中而改变卡片尺寸。
- 我的标准两列；菜单卡内容过窄或字体放大则单列。工具条在窄窗口换行，不能挤压导出/刷新等动作。
- 所有页面的标题、工具条、列表、末尾提示和一级导航可沿纵向滑动。长列表用一套有限高度 `LazyColumn`/`LazyVerticalGrid`；多列条目由 lazy 行或 grid span 组织，禁止在无界 `verticalScroll` 中放无界 lazy 网格。
- 业务弹窗宽度默认约安全区的 90%，按类型设最大宽 1100–1200 dp；最大高度不超过扣除系统栏/IME 后的 90%。受限高度内由单一内容滚动承载标题、字段、列表和操作；右上关闭附着可见外壳。
- 不绘制滚动条和源图的向下箭头；保留惯性、键盘及无障碍滚动。弹窗打开时阻止底层滑动，状态反馈不重置滚动位置。
- 触控区域至少 48×48 dp；装饰无语义，按钮有明确名称，禁用/满星状态不占错误焦点。错误通过文字和符号表达，不能只靠颜色。

## 9. 风险与回滚

- 资源重建与原图存在差异：以场景、配色、形状、排版和吉祥物关系为验收重点，在主设备上校准，不承诺合成图逐像素一致。
- 多张场景与透明插画可能增大 APK 和内存：按实际窗口选择尺寸、保留足够清晰度并避免过度解码；只打包使用资源，设计 ZIP、完整画板和下载缓存不进入 APK。
- 横屏高度和字体缩放容易压缩内容：统一安全区和可滚动外壳；先保证可操作，再校准装饰占比，不整体缩小触控区域。
- 提取大文件可能影响 ViewModel 作用域、录音清理和列表 key：保留根层编排及生命周期，分页面替换，练习行共用布局并做状态回归。
- 字体是近似手写风格：完整字库、缺字回退和识字易读性需真机确认；如字体不适合教学，可在主题统一回退系统字体，不改数据。
- 回滚通过撤销本需求的界面/资源/方向改动恢复旧 UI；没有数据迁移和服务端部署，学习数据继续兼容。
