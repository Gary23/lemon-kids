# 设计：从帮助记录收录已认识的字

## 问题分析与目标

帮助记录表保存 `requested_character`、`character_index`、词句文本及来源，但目前列表只有删除和下载。智能添加识字的弹层与 `evaluate-reading` 已支持词句预览、编辑、保存到已认识，以及已认识字重新置顶；现有预览总会请求 DeepSeek，因此需为帮助记录提供优先读取历史词句的预览方式。

目标是让家长对单条帮助记录完成“查看既有词句／生成 → 编辑 → 收录 → 清理本条记录”，并让失败可见、可重试。

## 方案与交互

1. 在“帮助过的内容”每条有效记录旁增加“加入已认识”按钮，保留原“删除”按钮。仅当 `requested_character` 为单个汉字，且 `character_index` 指向该条文本中的同一个字时启用；旧数据无法定位时显示不可操作状态。
2. 点击后打开复用智能添加识字布局的单字弹层，固定目标字并自动加载预览，显示加载态。词句字段保持可编辑；隐藏删除整组、生成内容及“添加到待认识”操作，底部只显示“确认并添加到已认识”。关闭弹层不改动数据。
3. 云函数新增帮助记录预览动作：按登录孩子和记录 ID 核对记录及目标字；先读取该字已有 `recognized_characters` 内容，再查 `child_literacy_characters` 中该字最近一次拥有可用词句的历史任务。词句均需属于目标字，取可用的 1～3 个词及 1 个句；历史内容不完整或不存在时，复用现有 `preview_literacy_tasks` 的 DeepSeek 生成规则。词句来源只限当前孩子，不能读取其他孩子。
4. 点击入口先调用 `check_helped_character`，按当前孩子与帮助记录 ID 验证目标字，并查询 `recognized_characters`。已认识时仅显示无需重复添加的提示弹窗，不进入编辑、不置顶、不删除帮助记录；仅在 `known_characters` 字库中的字仍进入编辑。检查失败提示重试，不按未认识继续。
5. 保存复用现有“添加到已认识”服务端校验与事务：未认识的新字创建已认识记录并以当前收录时间排到顶部；若检查后其他设备已收录该字，保存接口再次校验并返回冲突，不覆盖、不置顶、不删除帮助记录。已有待认识任务可直接完成收录。保存响应必须确认目标字确已创建。
6. 保存成功后按记录 ID 和当前孩子删除**被点击的这一条**求助记录，完成后关闭弹层并刷新列表、下载内容及首页。若保存失败，弹层保留编辑内容及记录；若保存成功而清理失败，显示“已加入已认识，帮助记录删除失败，可重试”，再次点击只重试清理，不产生重复收录。

## 数据与接口边界

- 客户端：`LemonLiteracyApp.kt` 中的帮助列表和生成弹层、`HelpedCharactersViewModel.kt` 的列表更新；`ReadingEvaluationViewModel.kt` 调用受保护的云函数预览/保存接口。
- 服务端：`cloud-functions/evaluate-reading/index.js` 按登录孩子过滤帮助记录和历史词句，沿用已有 DeepSeek 与收录逻辑；保存时复查已认识状态。`supabase/sql/20261009_helped_character_recognized_content.sql` 用于帮助来源的待认识内容收录，不新增补充需求迁移。
- 不改 `known_characters`；已认识字继续存于 `recognized_characters`。从帮助记录来源关联的任务可能对应别的主字，因此查词句必须按被标红的目标字匹配，不能直接使用该来源任务的词句。
- 求助记录删除仍按当前孩子及记录 ID 限定；其他同字求助记录保持原样。

## 风险、验证与回滚

- 历史任务可能只有不完整词句，或词句含目标字但不适合教学；预览仍可编辑，保存前使用现有校验。
- 保存与清理分两步时可能出现“已收录但求助记录仍在”；界面明确提示并支持重试，不能误报全部完成。清理若需更强原子性，再以数据库事务 RPC 实现。
- 自动测试覆盖历史内容命中、缺失时 DeepSeek 回退、跨孩子隔离、目标字校验、已有字置顶、保存失败不删除、清理失败可重试和列表更新；执行 Android 构建及云函数相关测试。
- 云函数部署前生成新 ZIP 并用 `unzip -l` 核验根目录，更新 `cloud-functions/evaluate-reading/README.md` 的部署包名。安装需用户确认；人工测试通过后才提交推送和标记完成。
- 回滚可撤销本次应用和云函数变更；若增加 SQL 迁移，优先设计为向后兼容并记录单独回滚步骤。

## 待用户确认的设计决策

- 历史词句优先级：先该字现有“已认识”记录，再查该字最近一次完整的历史认字任务；内容不完整时走 DeepSeek。
- 保存成功只删除被点击的那条帮助记录，同字其他记录继续保留。
- 若已经收录成功但删除失败，保留记录并显示重试提示，不把整次操作报告为完成。
- 已认识字仅提示无需重复添加；只在字库的字继续添加；检查与保存之间发生的并发收录由保存接口拒绝。
