# 设计：认字学习弹层对齐 UI 效果图

> 版本：v1，2026-10-14。范围：`kid-literacy-app`。状态：已批准。

## 问题分析与目标

当前 `CharacterStudyDialog` 通过通用 `GardenDialogFrame` 显示：标题被放在弹层内的浅色卡片中，面板采用通用白色圆角，分类只用文字小标签，行结构是“内容卡 + 控件 + 两行提示”，底部通过按钮位于滚动末尾。A09/A10 的主视觉则是白色奶油主体上叠云朵标题、左侧柠檬、四角花草，分类标签更醒目，行内星位、文字底块、五点和按钮有清楚的固定槽位。当前状态切换规则和点读交互已有实现，视觉调整须建立在相同数据与交互之上。

目标参考：[A09](../../ui-design/kid-literacy-app/design-concepts/ui效果图/landscape-recognition-garden-character-study-dialog.png)、[A10](../../ui-design/kid-literacy-app/design-concepts/ui效果图/landscape-recognition-garden-character-study-result-state.png)及[资源清单 A09/A10](../../ui-design/kid-literacy-app/design-concepts/安卓UI开发资源/逐页元素清单.md#a09-朗读练习弹窗)。源图为约 1586×992 px 的合成图，不直接把像素值当 dp；按目标 pad 的可用窗口和安全区校准相对比例。

## 范围与实现方案

1. **独立学习弹层外壳。** 为首页学习弹层建立专用外壳，不改变其他表单弹层的 `GardenDialogFrame`。使用现有可用的云朵、柠檬、花草等本地分层素材组合标题与装饰，奶油白主体保持圆角、白描边和遮罩；标题显示“{当前字}的朗读练习”，当前字用珊瑚色强调，副标题保留“长按汉字可听正确读音”。关闭按钮附着外壳右上角并满足 48dp 点击区。装饰不遮挡文字和操作，也不成为无障碍焦点。
2. **分类与练习行。** 字、词、句的标签分别用浅珊瑚或浅绿底、嫩芽图标、说明文字和细分隔线表达。练习行采用浅蓝底和细描边；左侧独立竖向星位、浅奶油色汉字底块，中右预留五点槽位，最右侧蓝色胶囊按钮。点击“开始”后当前行显示蓝色五点动画，结果到达后隐藏；结果错误时错字标红、按钮显示“重试”，仅评测故障等非逐字读错原因在行内显示提示。已完成项保留几何槽位，只隐藏五点与操作内容。
3. **固定布局与滚动。** 沿用 `StudyPracticeRow` 作为准备、录音、评测、错误、满星的共同几何结构。标准横屏尽量保持一行排布；宽度不足或大字体时改为纵向排布，保留文字、按钮和星位可触达。弹层标题和底部“通过”固定在外壳可见区域，练习列表独立纵向滚动；可用高度不足时允许整个内容进入可滚动布局，避免底部按钮或关闭入口被裁切。切换状态不重置列表滚动位置，不显示滚动条。
4. **底部通过与确认。** 将绿色大胶囊“通过”作为弹层底部主动作，宽度和装饰参照 A09/A10；仍须点击后打开现有确认弹窗，成功、失败、处理中和已完成状态按当前业务规则展示，不借视觉对齐取消确认步骤。
5. **真实内容。** 主字、每个词和待认识句子由真实 `LiteracyCard` 生成；长词句、音频缺失、评测失败与已认识复习都按现有规则处理。参考图中的四行和四颗星仅作画面示例，不锁定行数或星数。

## 风险、验证与回滚

- **动态高度与大字体：** 装饰和固定底部区域可能挤压列表；按可用高度设置上限，必要时整体滚动，并在目标 pad 及放大字体检查末尾动作。
- **状态跳位：** 共用练习行槽位，不按状态插拔外层布局；录音、评测、错误与满星检查行高和列表偏移。
- **位图缩放：** 分层素材只用作装饰，按宽高比裁切/缩放；不把整张合成效果图铺成弹层。
- **回滚：** 本需求界面和新增资源集中在应用模块；如人工验收不通过，按反馈修正，必要时恢复旧弹层视觉组件，业务状态逻辑保持现有实现。
- **自动验证：** `./gradlew :kid-literacy-app:assembleDebug :kid-literacy-app:lintDebug :kid-literacy-app:testDebugUnitTest`；具体测试结果、安装设备及人工结论在批准设计后写入 `执行.md`。

## 验收与待确认决策

以目标 pad 横屏标准字体对照 A09/A10 检查弹层外壳、标题、分类、行内槽位和底部动作；再验证录音、结果、满星、长内容与大字体。参考图是合成效果图，验收侧重层级、比例、颜色和交互稳定性，逐像素误差不作为独立失败条件。

待确认的范围决策：本单仅处理首页点字后的学习弹层及其朗读/结果状态，不包含智能添加、发音标注等其他弹层。

## 已验收缺陷设计归并（2026-10-15）

前三轮设计均已分别获得用户明确批准并在目标 Pad 安装、人工验收。最终方案以专用 `StudyDialogFrame` 组合云朵、天空、柠檬、光芒和花草，按 A09/A10 的横屏比例收紧弹层；`StudyPracticeRow` 统一字词句行的星位、文字、点阵与按钮槽位，字词行加高并放大加粗正文及星星。待命和结果不绘制点阵；开始后只在当前行播放蓝色五点动画。逐字标红的读错结果不再显示重复叹号和整句提示，其他评测故障仍显示原因。红蓝行按钮共用尺寸、触控与动态文案，底部花草置于“通过”操作层后方。真实评测、星级、点读、家长确认及数据依赖保持原方案。构建、Lint、单元测试、安装与人工结论见[执行](执行.md)。

## 已验收的第四轮缺陷设计归并（2026-10-15）

第四轮按已批准的缺陷设计，使用 Compose 绘制蓝色“开始”、红色“读完／重试”的单层渐变、细外描边与统一胶囊形状，保留原按钮槽位和触控尺寸；标准横屏以星位实际宽度加 10dp 定位文字框，动态约束文字框宽度，窄窗口沿用独立的 10dp 间距。按钮和间距在 Pad 人工验收通过，自动测试与安装结果见[执行](执行.md)。

## 已验收的第五轮缺陷设计归并（2026-10-16）

用户于 2026-10-16 批准设计。首页学习弹层在正确或已识别错字的评测结果中清空冗余行内消息，不绘制对应叹号；权限、准备、连接、超时和未识别有效朗读等故障仍显示原因。`StudyStarRail` 星号由 18sp 调至 21sp，点亮色由 `#FFDA4C` 加深为 `#FFC83D`，不扩大星位或按钮。练习列表改为在弹层生命期内持续组合的纵向滚动 `Column`，字、词、句使用稳定 key；滚动不再销毁行内 `ReadingDialog`、评测结果或 SDK 控制器，关闭弹层仍释放会话。长内容可滚动至末项，标题和底部操作保持固定。自动测试、安装及用户验收结论见[执行](执行.md)。
