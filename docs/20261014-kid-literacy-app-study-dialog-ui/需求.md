# 需求：认字学习弹层对齐 UI 效果图

- 需求编号：`20261014-kid-literacy-app-study-dialog-ui`
- 日期：2026-10-14
- 提出人：用户
- 应用范围：`kid-literacy-app`
- 原始需求：“开始新需求，这单需求将认字的弹出层与ui效果图对齐”

## 背景与目标

首页点击汉字后的单字学习弹层已可完成字、词、句练习，但现有通用弹窗外壳、标题区、分类标签、练习行及底部动作与 A09 朗读练习、A10 朗读结果效果图仍有明显差异。本次按这两张效果图优化该弹层的视觉层级和布局，并保留真实学习状态及可操作性。

“认字的弹出层”在本需求中暂界定为首页点字后的学习弹层，包含准备、录音、评测、成功、错误和满星状态，以及该弹层内的家长“通过”入口。待认识/已认识列表的发音标注、智能添加和其他确认弹窗不在本单范围；若用户批准设计时另行指定范围，以批准后的设计为准。

- 保留现有评测、点读求助、星级、手动通过、待认识字词句及已认识字词复习规则；不修改接口、数据库、云函数或其他应用。

## 验收标准

1. 目标 pad 横屏标准字体下，弹层外壳、云朵标题、柠檬与花草装饰、关闭按钮、字/词/句分类、练习行、五点状态和底部“通过”按钮，与 A09/A10 的结构、比例、色彩及间距接近。
2. 标题与数据真实绑定；分类按任务内容显示，已认识字复习不凭空增加句区；每个词仍独立成行。
3. 准备、录音、评测、错误、成功和满星之间切换时，同一练习行的星位、正文、动画、按钮及提示槽保持稳定；错误字标红，评测连接等异常保留具体提示，重试可用。
4. 弹层内容增长、字体放大或横屏高度缩小时仍可滚动到全部练习项和“通过”；关闭按钮始终可达，无可见滚动条，触控目标不小于 48dp。
5. 自动验证覆盖构建、Lint、现有练习行测试及本次必要的布局/状态检查；安装与人工测试按门禁单独确认。

## 已验收的三轮缺陷结论（2026-10-15）

用户在 Pad 上验收前三轮修正，并明确要求将本次需求已有的补充与缺陷标记完成。实际没有单独的补充需求流程；第三轮五项经用户确认均为缺陷。三轮最终有效规则如下，覆盖上方初始标准中已失效的五点及读错提示描述：

- 第一轮原始反馈：“样式还是有差异 1. 弹出层标题部分的背景图与效果图完全不一样 2. 弹出层的宽度不需要这么宽，我觉得整体比例和ui不一样 3. 弹出层关于读错的红色，这个颜色与ui不一样 4. 读错的提示语，叹号和文字换行了 5. 圆点动画的圆点大小与ui不一致。”
- 第二轮原始反馈：“还有问题 1. 正在录音请朗读的位置不对 2. 重试按钮颜色不对 3. 按钮、字的方框、星星的放款没有水平居中 4. 字应该加粗 5. ‘x的朗读练习’这里的标题的背景图还是不对。”
- 第三轮原始反馈：“1. 圆点动画默认是不展示出来了，只有点击开始，圆点动画才开始展示并开始执行动画效果，我认为就直接用蓝色的圆点就可以，不需要用红色的 2. 红色叹号的‘这次还没有点亮星星，看看红色的字，再读一次吧’，这句话我认为没必要展示，直接删除就可以，因为字标红已经说明了有问题，没必要有提示语 3. 字、词列表项的元素我认为应该高度增加一些以便增大字、词的字号，左侧星星的图标也应该增大一些，按钮不需要增大 4. 重试按钮还是和其他按钮不一致 5. 弹出层底部的通过被背景图盖住了一部分，这个按钮应该在背景图的上层。”用户明确确认五项均按缺陷处理。

1. 云朵、浅蓝天空、柠檬和花草组成动态标题背景；弹层在 Pad 横屏保留明显左右留白，分类、练习行和底部“通过”完整可见。
2. 录音提示显示在当前行点阵下方；字、词行加高，文字加粗放大，星星同步放大，按钮、文字框及星位在各自槽内水平居中。标题继续展示真实汉字。
3. 待命和结果状态隐藏五点；点击“开始”进入朗读后，仅当前行显示并播放蓝色五点动画，评测结束后隐藏。
4. 读错时逐字标红，不再显示红色叹号及冗余整句提醒；准备、连接、权限或超时失败仍给出具体原因。红色重试按钮与蓝色行按钮保持相同尺寸、居中和触控规则。
5. 底部“通过”位于花草背景上层，完整可见且可点；点击后仍打开原有确认弹窗。

## 已验收的第四轮缺陷结论（2026-10-15）

用户反馈：“开始、读完、重试，按钮和效果图都不一样，严格按照效果图的样式来做”；“文字方框的左边框和星星方框的右边框重合了，两者应该有一定的距离”。用户批准设计并授权安装后，已在 Pad 人工验收，明确要求本轮缺陷标记完成。蓝色“开始”及红色“读完／重试”使用 A09/A10 对应的单层渐变、细描边、统一圆角和居中文案；星星框与文字框在字、词、句及各状态均保留可见间距，按钮尺寸与触控规则不变。

## 已验收的第五轮缺陷结论（2026-10-16）

用户原始反馈：“1. 我发现读对后，也有个叹号提示语‘读对啦’，这个也要删除 2. 星星的黄色我希望可以再增大一点，黄色加深一点点 3. 当一个字读错后显示重试按钮，再次状态下如果滑动弹出层让这个字滑动到视窗之外再滑动回来后，这个字就从重试变成了正在朗读状态，这是不对的，不应该自动改变状态，另外词也有这个问题，你需要修复一下”。用户批准本轮设计与安装，并于 2026-10-16 确认本次需求、所有补充与缺陷均测试通过。

1. 字、词读对后不显示“读对啦”等重复提示或对应叹号；逐字读错仍只标红，权限、连接、超时和无法识别有效朗读等故障仍提供可操作原因。
2. 已点亮的黄色星星在原星位内略微放大并加深，空星、按钮及文字框间距保持清楚。
3. 字、词读错出现“重试”后，滚出视窗再滚回仍保留该次结果、错字、星数及“重试”状态；滚动本身不重启录音或评测，明确操作或关闭弹层才改变会话。
