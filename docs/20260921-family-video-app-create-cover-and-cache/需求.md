# 需求

- 需求编号/目录：`20260921-family-video-app-create-cover-and-cache`
- 日期：2026-09-21
- 应用范围：`family-video-app`（包括它专用的 `supabase/functions/family-video-drive/` 云盘接口）
- 提出人：用户

## 原始需求

1. 新建媒体条目页面中，将“云盘目录”放在“类型”之后；封面直接读取所选云盘目录下名为 `folder`、后缀为 `png`、`jpg` 或 `jpeg` 的文件，并在页面预览。
2. 将家长 Tab 名称改为“我的”；“我的”页面的 123 云盘连接状态改为本地缓存，避免每次进入页面都重新连接/请求状态。

## 背景与目标

当前新建页先要求手动从手机选择并上传封面，云盘目录字段排在封面之后；云盘目录浏览接口也只返回子目录。当前“家长”页每次重新进入都会请求云端连接状态。

本需求要让新建条目的封面跟随已选择云盘目录中的约定文件，并让“我的”页优先展示本机保存的、非敏感的连接状态。

## 非目标与约束

- 不改变已创建条目的封面编辑方式，且不删除既有 Supabase `video-covers` 文件。
- 不下载、移动或上传 123 云盘文件；123 access token、应用密钥、云盘密码和临时封面 URL 都不落盘。
- 不修改数据库结构、RLS 或其他应用。
- 云盘接口仍须验证登录用户及家庭；临时预览链接仅用于当前界面。

## 依赖与影响

- 依赖已部署的 `family-video-drive` Edge Function 及其 123 OpenAPI 配置。
- Android 与同一应用专用 Edge Function 的调用链为：新建页 → `CloudDriveProvider` → `family-video-drive` → 123 OpenAPI。
- 本流程不处理 `parent-app`、其他 Android 应用、共享模块及数据库迁移。

## 验收标准

1. 新建媒体条目中，字段顺序为名称、类型、云盘目录、封面；选择具体云盘目录后自动查找该目录直接子项中的 `folder.png`、`folder.jpg` 或 `folder.jpeg`（不区分大小写）并预览。
2. 不存在匹配文件、读取失败或文件不能生成临时链接时，页面给出可理解提示且不能保存；不使用手机本地选图作为新建页替代路径。
3. 底部 Tab 的“家长”显示为“我的”，页面标题与文案相应改为“我的”。
4. 首次没有本地缓存时读取连接状态；之后在缓存有效期内重新进入“我的”页不再请求连接状态。点击连接/重新连接成功后更新缓存；缓存不保存任何密钥、token、密码或临时 URL。
5. `:family-video-app:assembleDebug` 自动构建通过；获得安装许可后在设备完成上述人工验证。

## 已合并的补充需求与缺陷

以下事项均属本应用及其专用 `family-video-drive` 云函数，未扩展到其他应用：

1. 首次 `folder_cover` 未部署导致 `folder.png` 无法预览/保存：已部署函数并完成未登录 401 核验。
2. 授权重复、保存后刷新慢或超时：服务端以“Edge 内存 → 受 RLS 保护且无客户端策略的短期 token 表 → 重新授权”复用应用级 token；仅在实际到期或认证拒绝时重新授权一次。用户已执行并核验对应 SQL。
3. 授权失败提示不清：区分授权响应超时、授权失败、目录读取慢和整体同步超时；失败诊断仅保留非敏感状态、尝试次数与耗时。
4. 目录封面读取被客户端过早取消：封面、目录、连接和播放地址均使用与服务端 85 秒预算匹配的 95 秒客户端窗口；完整同步保持 55/65 秒预算，失败保留既有视频。
5. 全目录扫描造成目录选择慢：`browse` 改为单页目录协议，支持加载更多及按登录用户隔离的 24 小时本地页缓存；刷新目录可绕过缓存，手动同步仍完整读取最新目录。
6. 封面定位扫描整目录造成超时：优先精确查找 `folder.png`、`folder.jpg`、`folder.jpeg`，未命中最多降级读取一页；定位元数据可复用，但短期下载链接不缓存。
7. 不同目录自动封面串图：服务端验证搜索结果父目录，以家庭和目录隔离封面缓存，并为定位结果签发短期归属凭据；Android 仅复用该凭据，且取消过期任务、在每个异步回写阶段确认选择序号及当前目录。

2026-09-21，用户明确要求将本需求关联的补充需求及缺陷 1 至 6 全部改为完成状态，并执行完成收尾流程；据此作为本流程最终人工验收结论。此前 `folder.png` 自动预览与保存已单独复测通过。所有改动均不移动或修改 123 云盘文件；短期 token、下载链接、密钥和原始上游响应不进入 APK、客户端缓存或日志。
