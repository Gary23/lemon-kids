# 设计

## 问题与目标

现有日历在内容区纵向排列月历和日期任务，未利用第 01 批固定横屏壳层；计划页只列出本周或下周的待完成任务，较远日期无法在计划页浏览。切换月份时选中日期仍停留在旧月份，容易造成月历和任务详情不一致。本批在 `kid-task-app` 内解决这些展示与浏览问题，保留真实任务的完成、撤销和朗读链路。

## 页面与交互方案

- 沿用第 01 批的 184 dp 左侧导航和主题令牌，不改顶层四入口或锁定横屏设置。以 Stitch MCP 中“平板横版：任务日历与足迹看板（修复布局版）”的完整截图及 HTML 为主参考，本地 `_1`、`_5` 截图补充日期格与任务状态细节。Stitch 画面使用 7:5 的月历/任务双栏：顶部放月份切换、当前年月、“回到今天”和任务状态图例；左侧月历下放四张月度统计卡，右侧依次是选中日期的真实打卡摘要、任务清单和演示寄语。成长足迹按本批需求另设演示区。内容区较窄时按月历、当日摘要、任务、演示卡的阅读顺序堆叠并可滚动，侧栏保持可达。
- 日期格只读取 `tasksByDate`：有任务且全部为 `DONE`/`VERIFIED` 显示完成色，有其他状态显示待处理色，无任务显示空闲色。今天和选中日期分别有可辨识标记；状态同时提供文字或可访问描述，不能只靠颜色。日期格可展示由真实任务派生的完成数或任务数，不伪造每日得星。日期详情沿用现有紧凑任务卡、分类、朗读、确认完成和撤销弹窗。
- 切换月份后，选中日期同步到目标月：若目标月是本月则选今天，否则选目标月 1 日；“回到今天”同时重置年月和选中日期。选择日期同时更新年月，以免任务详情和月份脱节。日期计算统一使用 `LocalDate`/`YearMonth` 和现有 `yyyy-MM-dd` 日期字符串，跨年和月末按日历规则处理。
- 选中日摘要中的任务总数、完成数、进度及空状态均从该日真实任务派生，任务状态更新后随观察流刷新。参考图的四张统计卡为累计打卡天数、本月小星星、全勤天数和打卡达成率；这些月度统计、鼓励寄语和成长足迹没有本批可核实的数据来源，统一由只读 `CalendarDemoUiState` 提供固定示例；每个演示区均标“演示”，不引用真实积分，不冒充家长留言，也不参与任务操作或服务端写入。
- 保留 `plan` 子页面及当前从个人资料页进入的路径，直到后续批次处理个人资料入口。计划页按日期升序浏览**全部未来有日期的真实任务**，不再限于本周/下周或仅 `PENDING`；展开日期后显示任务真实状态和积分信息。计划页保持只读，完成/撤销仍在日历日期详情执行。无未来任务时展示明确空状态。

## 涉及文件与数据流

- `feature/calendar/CalendarScreen.kt`：横屏布局、月历、真实当日摘要与标注清晰的演示看板。
- `feature/calendar/CalendarViewModel.kt`：日期选择、月份切换和任务聚合；完成/撤销继续调用现有 `TaskRepository` 接口。
- `feature/plan/PlanScreen.kt`：未来任务按日期分组浏览与只读状态展示。
- `ui/components/TaskCards.kt`、`ui/theme/`：仅复用或按本批页面需要调整组件视觉，不改变首页任务行为。
- `src/test/`：覆盖跨年/月末切换、选中日期同步、真实日状态/摘要和未来计划范围。

`TaskRepository.observeChildTasks → CalendarViewModel.tasksByDate → 月历/当日任务/真实摘要`；演示看板仅在 UI 层读取固定示例。计划页同样读取现有任务观察流，不新增共享模块、数据库、云函数或接口字段；`ProfileScreen → plan` 路由继续可用。

## 验收与验证

1. 在第 01 批固定横屏侧栏内，月份切换、回到今天、选日和跨年边界正确；月历与日期详情始终指向同一月份。
2. 真实任务按选中日期展示，完成/撤销与朗读可用；完成数和进度随真实任务状态变化，无任务日显示空状态。
3. 计划页能浏览本周以外的未来任务及真实状态，仍可从现有入口进入和返回。
4. 月度统计、足迹和寄语均可见“演示”标识，且不改变真实余额、任务状态或服务端数据；窄内容区可滚动浏览。
5. 自动测试运行 `:kid-task-app:testDebugUnitTest` 与 `:kid-task-app:assembleDebug`；通过后再单独取得安装许可，安装到用户指定设备并等待人工验收。

## 风险与回滚

月份边界和日期解析可能使日历与任务错位；单元测试覆盖跨年、月末及无日期任务。演示统计若与真实数据混排可能误导用户，因此每个演示区独立标注，真实当日摘要单独呈现。较窄横屏可能挤压两栏，内容区使用宽度适配和滚动，人工检查长标题、任务较多和弹窗。若需回滚，只回退本批日历与计划页面及其 UI 派生状态；仓库接口和第 01 批公共壳层不变。
