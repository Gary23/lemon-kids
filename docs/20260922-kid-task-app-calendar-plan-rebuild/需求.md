## 原始需求

作为柠檬任务全面 UI 重构的一部分，按 Stitch 的任务日历与足迹看板完成日历和计划域重构；尚无后端能力的设计元素允许使用演示数据。

## 本批目标

重构任务日历、日期详情和未来计划浏览，使其适配横屏平板；补齐“每日打卡摘要、月度统计、足迹/鼓励寄语”视觉与交互展示。

## 非目标

- 不新增或变更任务、奖励、孩子档案的服务端字段。
- 不改动首页、奖励中心或成长成就中心的业务功能。

## 约束与依赖

- 视觉实现必须先通过 Stitch MCP 获取对应屏幕的实际截图与 HTML，以 MCP 实际效果为主要依据；仅在 MCP 缺失或不明确时参照本地下载的 `ui` 目录。本规则适用于本次及后续柠檬任务 UI 修改。日历主参考为“平板横版：任务日历与足迹看板（修复布局版）”，本地 `_1`、`_5` 仅补充细节。
- 依赖批次一的壳层/设计令牌；批次一未完成时本批不进入实现。
- 现有任务按日期聚合为真实数据源；月度统计、鼓励寄语和足迹若无可靠数据源，使用明确的演示数据。

## 验收标准

1. 可切换月份、选择日期，并看到该日真实任务及完成状态。
2. 横屏下日历、选中日任务和打卡摘要形成清晰的主从布局；窄屏不中断浏览。
3. 未来日期任务继续可浏览，既有完成/撤销操作保持可用。
4. 无数据源的统计、寄语和足迹均以“演示”语义展示，且不写入服务端。
