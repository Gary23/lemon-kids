# 需求：家长端诊断字段中文说明

- 日期：2026-10-19
- 范围：`parent-app` 的认字诊断记录页
- 提出人：用户
- 原始描述：“家长端我看到最新的查询，和原来给我的信息并无不同”“现在显示的是英文的字段，看不懂是什么意思”“继续”；随后追问 `PronAccuracy: -1`、`missing_words` 与腾讯原文大量英文字段的含义，并要求家长端增加说明文档按钮，说明内容取自腾讯官方文档。

## 背景与目标

当前记录列表和详情直接显示 `failureReason`、`words` 及腾讯评测 JSON 的英文键名与代码，家长难以理解。页面应先用中文说明记录、标红和可确认的评分含义，再提供腾讯原始 JSON 供核对和复制。

## 验收标准

1. 诊断记录页有明确的“字段说明”按钮，打开家长可读的说明页，覆盖腾讯逐项结果与评测原文中有官方定义的返回字段、数值范围、特殊值及枚举值，并给出腾讯官方文档入口。
2. `PronAccuracy=-1`、`MatchTag=0…4` 等特殊值按腾讯官方定义解释，区分“腾讯判定”与“孩子实际是否开口”；未由官方解释的字段或取值不得猜测。
3. `missing_words`、`low_pron_accuracy` 等本应用生成的诊断原因单独标注为“柠檬认字判定”，说明生成条件，不混称腾讯返回字段。
4. 记录列表和详情的主要内容也应使用清楚的中文标签；原始 JSON 的键名、层级、值和复制能力保留，方便与说明页对照。
5. 旧记录、缺失字段及未收录的腾讯字段有明确边界说明；页面仍只展示当前家庭孩子的记录。

## 边界与依赖

本需求仅修改家长端显示。依赖既有云函数返回的诊断摘要与受限腾讯原始 JSON；不改变腾讯评分、认字端标红规则、上报格式或云函数接口。当前原始 JSON 展示流程仍处人工测试阶段，此体验调整按独立家长端流程处理。
