# 设计：诊断记录中文说明

## 问题与方案

`ReadingDiagnosticScreen.kt` 当前把 `failureReason`、`words` 作为 JSON 文本显示，展开后虽然能看到腾讯评测原文，但没有中文解释。诊断页新增“字段说明”按钮，打开应用内可滚动的说明页；其中按“腾讯返回字段”“腾讯枚举及特殊值”“柠檬认字生成的诊断字段”分节，保留原键名供对照，每节附腾讯官方来源链接。列表优先展示“字／词／句”、目标文本、标红的实际字和中文原因；详情按字展示腾讯已知评分项的中文名称、原值及必要说明。原始 JSON 保留独立区域、原有键名与值及复制能力。

腾讯官方 Android SDK 返回说明和数据结构说明定义：`PronAccuracy` 范围为 -1～100，-1 表示“完全不匹配”；它是特殊值，不展示成“负一分”，也不能仅凭此值断定孩子没开口。`MatchTag`：0 匹配、1 新增、2 缺少、3 错读、4 未录入。此前样本“树”同时是 `PronAccuracy=-1`、`MatchTag=2`，说明腾讯判为缺少项。`PronFluency`、`PronCompletion` 范围 0～1，词模式下整体值无意义；`SuggestedScore` 范围 0～100。`Word` 为当前词，`ReferenceWord` 为参考词；`Words` 为逐项数组，`PhoneInfos` 为音素详情；`MemBeginTime`、`MemEndTime` 为毫秒时间点，`SessionId`、`RequestId` 为会话与请求标识。说明页覆盖官方数据结构列出的其他返回字段，包括断句结果、音素、匹配候选序号与主题词标记，并准确区分顶层、逐项及音素层级。同名字段按所在层级说明。若实际 JSON 含官方文档未列字段，展示原键与原值，并标记“当前官方资料未查到定义”。

`low_pron_accuracy`、`missing_words` 等为客户端生成的代码，非腾讯字段。前者表示客户端发现逐项 `PronAccuracy` 数值低于 60；当前实现也会把 -1 归入该代码。后者表示客户端没有解析到非空的 `Words` 对象数组，可能是没有返回、数组为空或回调结构无法解析；不能据此断定孩子没读。应明确区分腾讯服务的结果与本应用的判定逻辑。标红位置按原文索引转成字；越界索引保留位置数字供排查。

说明页字段表以腾讯官方文档为依据，并提供“打开腾讯官方文档”外链；不把 `Word` 当作实际语音转写，也不从单个评分推断孩子是否朗读。腾讯原文仍原样查看和复制，不在客户端动态抓取或重写官方网页，以免文档变动影响页面可用性。

## 官方依据（2026-10-19 核对）

- 腾讯云[Android 音频数据评测说明](https://cloud.tencent.com/document/product/884/84102)：Android SDK 返回对象、字段范围、`PronAccuracy=-1`、`MatchTag=0…4`、时间与音素等字段。
- 腾讯云[评测维度](https://cloud.tencent.com/document/product/884/84139)：评分维度、匹配标记各值、`Word` 与 `ReferenceWord`、实际案例。该文档的例子表明 `MatchTag=0` 仍可能伴随偏低分数，且 `MatchTag=2` 表示腾讯判为缺少项。
- 腾讯云[API 数据结构](https://cloud.tencent.com/document/product/884/19320)：云端返回结构与其他字段。若 SDK 结构与 API 文档有差异，以实际 Android SDK 返回字段的官方说明为优先。

页面说明：腾讯评分和匹配标记不能还原孩子实际读音，也不能单凭低分确定读错的具体原因。原始 JSON 中没有可靠中文释义的键，仍按原键展示，不编造字段含义。

## 文件、接口与验证

- 修改 `parent-app/src/main/java/com/lemonkids/parent/feature/profile/ReadingDiagnosticScreen.kt` 及必要的家长端导航文件，实现说明按钮、说明页、官方链接、中文标签、原因映射、标红字展示及缺失值处理。
- 仅消费现有查询结果；不修改云函数、认字端、数据契约和鉴权。
- 自动验证：家长端 `assembleDebug --offline`；针对原因、标红索引与无效分数的可测试逻辑做必要验证。自动测试后须再取得用户安装确认，安装到指定手机后等待人工测试确认。
- 人工验收后同步 `parent-app/README.md` 中诊断页面的当前说明；原始 JSON 仍可复制。

风险是腾讯可能返回未见过的字段和代码；页面保留原值并以“暂无可靠解释”提示。回滚时恢复原页面显示，接口不受影响。
