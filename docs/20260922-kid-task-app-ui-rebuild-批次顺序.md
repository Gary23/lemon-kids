## 执行规则

1. 先完成批次 01，作为后续页面共用的导航、主题令牌和组件基础。
2. 批次 02、03 在批次 01 自动测试通过且公共接口稳定后才能进入执行；两者不互相阻塞。
3. 每个批次仍需独立获得设计批准、自动测试通过、安装许可和人工测试确认后，才能标记完成。
