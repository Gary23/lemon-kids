- 仅锁定本应用活动方向，不修改系统全局旋转；目标为 Pad 全屏横向窗口，不单独设计系统强制窄窗口的竖屏 UI。

## 验收标准

1. 从竖持设备启动应用后切换并保持主横屏方向；公共壳层始终展示收窄后的左侧四项导航与侧栏底部儿童摘要，不出现竖屏底部导航。
2. 今日任务具有完成进度、待办/已完成区、分类色、星星奖励、完成确认与庆祝反馈。
3. 真正的任务读取、完成、撤销、积分刷新和提醒不回退为假数据。
4. 视觉符合设计稿的柠檬黄、薄荷绿、珊瑚粉、天空蓝、软弹圆角和按压层次。
5. 今日任务始终使用横屏进度和双列任务区；待完成列比初版更宽，已完成列仍可读可操作。Pad 全屏横向运行时，登录/绑定、导航、任务完成与撤销仍可用。
6. 今日任务不展示顶部时段问候及其右侧连续天数、积分标签；待完成及已错过任务卡片右端固定展示带可访问名称的圆形对号按钮，不再展示大号文字完成按钮，点击后沿用原完成确认与业务流程。
7. 待完成及已错过任务卡片的 `+n 积分` 紧随分类标签展示；长分类可截断但积分保持可见，卡片底部不显示积分、截止时间或空占位。
