# 手动测试

前提：确认交付并替换、重启控制台后再执行。重启控制台本身不停止 Docker 或 Supabase。开始启停测试前，请结束正在使用本地数据库的调试操作。

## 页面与专用入口

1. 双击 `/Volumes/pan/lemon-kids-local-supabase/打开本地服务控制台.command`，在 `http://127.0.0.1:8765/` 刷新页面。
2. 标题应为“Lemon Kids 本地服务控制台”，Colima、Docker 标注为共享环境。等待首次检查完成，当前应显示 Supabase“就绪”，容器区只有 Lemon Kids 的十个容器。
3. 点击 Studio，应打开 `http://127.0.0.1:54423`；邮件入口应为 `http://127.0.0.1:54424`。页面 API、数据库应分别显示 `54421`、`54422`。
4. 确认每张状态卡有“上次确认”和时间；“查询诊断”与“启停操作记录”分开展示。

## 停止与启动

1. 点击“停止服务”，等待操作记录结束。Lemon Kids 应停止；没有其他运行容器时 Colima 也停止，此时 Docker/Supabase 显示依赖未就绪。若还有其他容器，则应说明保留共享 Colima。数据不会被清除。
2. 点击“启动全部服务”，等待专用容器就绪。启动命令结束与容器健康就绪可能存在时间差，过程中允许显示“启动中／部分运行”。
3. 再次打开 Studio，确认原有 Lemon Kids 表和数据仍在；只查看即可，无需写入数据。
4. 在终端执行下面的只读检查，运行中的 Supabase 容器名称应以 `_lemon-kids-local` 结尾，不能出现 `_local-supabase-service`：

```sh
cd /Volumes/pan/lemon-kids-local-supabase
. ./container/env.sh
docker ps --format '{{.Names}}'
```

## 超时与历史快照（可选隔离模拟）

此项使用独立端口和模拟命令，不影响真实服务，不需要拔盘或强行停止 Docker。

1. 在终端执行：

```sh
cd /Volumes/pan/lemon-kids-local-supabase
python3 tests/preview.py timeout
```

2. 打开 `http://127.0.0.1:18765`，页面标题带“模拟预览”。Supabase 应显示“状态未知／响应超时”，上次确认仍为“就绪”并带时间；容器行保留并标注“历史快照”，不代表当前状态；查询诊断显示具体超时，启停按钮禁用。
3. 回到终端按 `Ctrl+C` 关闭模拟。真实控制台 `8765` 应保持正常。

## 关闭控制台

1. 在真实控制台点击“关闭控制台”，页面提示关闭。
2. Studio 应仍可打开，服务保持运行；重新双击入口，控制台应能恢复检测。

## 验收反馈

请反馈上述各项是否通过；若有异常，记录发生步骤、页面状态、诊断及操作记录。请勿复制包含密钥的 Supabase CLI 输出。视觉效果和实际启停需由人工验收，自动测试未实际启停业务服务。
