# 需求：奖励兑换页图片闪回默认封面

- 需求编号/目录：`20261009-kid-task-app-reward-image-flicker`
- 日期：2026-10-09
- 应用范围：`kid-task-app`
- 提出人：用户
- 原始描述：

> 切换到最新的柠檬任务app分支，我遇到一个问题，柠檬任务app内我打开奖励兑换页面，图片先是变成了我在家长端配置的图片，然后往下滑动页面的时候图片又变为了默认图片，之后1秒钟后又变回了配置的图片

## 背景与目标

家长上传的奖励图片已能在孩子端显示，但页面使用过程中会短暂闪回预设封面。目标是在奖励图片已成功显示且图片配置未变时，滚动、页面恢复及奖励数据刷新均持续显示该图片；图片真正缺失或加载失败时仍可显示预设封面。

## 范围、约束与依赖

- 只处理孩子端奖励页的图片地址状态和封面显示；保留大/小心愿布局与现有兑换规则。
- 依赖家长端已配置的 `image_path`、`:shared` 的签名 URL 接口以及私有 Storage 读取权限；本次不修改家长端、共享仓库或数据库。
- 签名 URL 有效期为 10 分钟，不能将其作为永久地址持久化；家庭或图片路径切换时不能沿用旧图。
- 原 `20261004-kid-task-app-reward-image-display` 流程已完成，本次作为新的孩子端缺陷流程记录。

## 验收标准

1. 已显示家长图片的奖励，进入页面后连续上下滚动、页面恢复以及手动刷新时，不因相同图片重新签名而闪现默认封面。
2. 家长替换或移除图片后刷新，卡片显示新图片或对应预设封面；不能展示其他家庭或旧路径图片。
3. 无图、签名失败、下载或解码失败仍显示预设封面；标题、星星、兑换功能不受影响。
4. 自动测试及构建通过，设备安装与人工复测按 `docs/README.md` 门禁执行。

## 跨模块影响

仅消费既有共享接口，不改变 `parent-app`、`:shared`、Supabase 的行为或契约。
