# `:kid-task-app`：孩子任务端

## 当前职责

孩子通过任务绑定码进入应用，查看/完成任务、查看日历、兑换奖励和管理个人资料。模块依赖 `:shared`，不应直接实现 Supabase 数据访问。

## 路由与约束

- 首次会话检查由共享 `AuthViewModel` 完成；未登录进入 `task_binding_code`，成功后进入 `task_main`。
- 任务端固定 4 个 Tab：`home`、`calendar`、`reward`、`profile`；`plan` 是子页面而非 Tab。
- 绑定页必须传递 `type = "task"` 和 Android `ANDROID_ID`。不得将其改为监控端的单设备重绑语义。
- 任务端会在本 App 私有存储中保存已验证的 `task` 绑定码。Supabase 会话无法刷新时，先尝试用该码静默恢复；仍失败则在根层显示不可关闭的恢复弹层，提供“重试刷新”和“使用绑定码登录”。主动切换账号或清除应用数据后必须重新绑定。
- 日历页采用横屏双栏：左侧月历以右上圆点表示状态、右下显示真实得星，右侧按选中日期展示摘要和平铺任务卡；首页任务卡维持独立布局。可切换月份、回到今天和选择日期，月份与选中日保持同步；内容区较窄时顺序堆叠并可滚动。
- 月历日期任务、完成状态、选中日任务数与进度均来自真实任务；日期详情保留任务朗读、完成确认和撤销操作。月度统计、成长足迹和鼓励寄语目前没有可靠数据源，逐处标为“演示”，不计入真实积分或写入服务端。
- “未来计划”从“我的成长”进入，按日期升序只读展示全部未来有日期的真实任务，包括本周以外及非待完成任务，并显示各任务的真实状态和积分；完成和撤销仍在日历日期详情操作。
- 任务完成和撤销依赖 `:shared` Repository/RPC。奖励页从家庭奖励目录读取真实心愿、本人积分余额、本月任务收益和兑换记录；兑换时由服务端事务扣星，使用前取消按原价退星。若星星已花费且余额不足，任务撤销由服务端拒绝。
- 奖励目录由家长维护，同一家庭的孩子共享启用的奖励，其他家庭的奖励不可见。一次性奖励全家总共只能成功兑换一次，未使用的兑换取消后恢复名额（奖励仍启用时）；常规奖励可重复兑换，每次生成独立记录。余额未取得时不可兑换，积分不足时显示差额；兑换须二次确认，失败不改变页面余额或记录并可重试。未使用的兑换可取消并按原价退星，已使用的兑换保留历史且不可取消，已取消记录仅留服务端审计；旧版有效兑换仍可在记录中辨识。
- 奖励兑换页的大心愿和小心愿卡片优先展示本家庭启用奖励的家长上传图片；无图、图片签名或加载失败时沿用原预设封面，名称、积分和兑换照常可用。进入页面或点击“刷新奖励”会重读目录并取得短期图片地址，家长替换或移除后刷新即可更新。孩子端没有图片修改入口，兑换历史仍只显示文字；图片读取依赖 `:shared` 的签名接口及 Supabase 私有 `reward-images` 存储权限。
- 有截止时间的待完成任务会在孩子端以本地通知提醒；首次启动需取得通知权限。
- `MainActivity` 固定主横屏方向；公共壳层始终使用 184 dp 左侧四入口导航，底部保留儿童摘要。今日任务顶部直接显示进度，不展示时段问候及重复的天数、积分标签；待办/已完成按 1.25:0.75 双列布局，待办及已错过任务使用卡片右端仅显示“打卡”的黄色文字操作按钮，并沿用原确认流程。待办及已错过任务卡在分类标签后显示真实 `+n 积分`，不在卡片底部显示截止时间；已完成卡标题下显示“获得 N 颗星星”。不提供竖屏版或底部导航。首页仅展示当日任务，首次会等待任务和分类均返回后再展示；未手动排序时按家长端配置的创建顺序分组，避免首屏重排。分类图标按分类稳定标识选择；分类颜色按当天可见分类集合分配，最多十类同屏不撞色，同一集合内刷新和任务排序不改变颜色。超过十类可能复用颜色，分类集合增删可能使部分分类换色。十种底色依项目 Stitch UI 色卡调整为较浅配色，今日待办及过期卡片的分类标签与左侧竖条直接共用同一不透明颜色。已完成任务会脱离原分类，统一置于末尾的孩子端专用“已完成”分组。
- 首页仅“待完成任务”列表支持整卡长按拖动，可跨分类重排；左侧无独立把手。长按卡片文字、空白或操作区会出现抬起、黄色描边、轻摆及触感反馈，实际拖动时邻卡让位；静止长按不自行换位，反复交换也不使无关卡片串位。短按朗读、打卡和普通滚动仍可使用；“今天已完成”列表不可拖动，拖动不会改任务分类、状态或积分。
- 待完成列表标题下不显示拖动提示行，拖动时也不出现该提示；空列表提示保留。任务卡显示并朗读当前任务实例的每日描述，内容由家长端逐日发布，不从任务库固定描述继承。
- 待完成顺序只保存在本机 App 私有存储，按孩子账号和任务日期隔离；退出重开、从后台恢复或任务刷新后继续使用已保存顺序。新待完成任务和撤销完成后返回的任务追加在末尾，已完成任务移出待完成列表；没有手动顺序时沿用默认分类顺序。保存失败会恢复先前顺序并提示重试。排序不向服务端、家长端、日历或桌面小部件同步；另一设备、卸载或清除应用数据后不恢复本机顺序。
- 今日任务的“神秘盲盒”在尚无解锁规则时仅展示不可点击的“即将开放”入口，不写入任务或奖励数据。
- 固定侧栏四入口名称为“今日任务”“任务日历”“奖励兑换”“我的成长”。奖励页按 Stitch 展示“我的星星银行”、大心愿、Pad 横屏三列小心愿和单列表真实兑换记录；刷新按钮位于星星银行，刷新中仍保持白字与深绿背景。不提供“投递新愿望”入口。成长页展示真实资料、等级、勋章和足迹，并保留计划、使用限制和切换账号入口。
- 固定侧栏孩子摘要与“我的成长”标题显示当前绑定孩子账号的 `users.name`；成长页姓名只读。资料加载中显示“姓名加载中”，字段为空显示“未设置姓名”，长姓名省略显示。侧栏摘要显示当前孩子的圆形头像和 `Lv.N` 角标；头像未取得时使用默认孩子图，成长快照未取得时不显示等级，切换账号不沿用前一孩子资料。
- 任务完成与撤销先在首页即时反馈，仓库写入成功后会主动刷新任务观察流；失败时恢复原状态。
- 应用从后台恢复时会刷新 Supabase 会话并立即重拉任务；网络暂不可用时最多八秒结束加载态，会话无法恢复时由根层登录恢复弹层接管，不会持续显示加载动画。
- 任务端提供标准 Android 桌面小部件“今日任务卡片”：作为首页当日任务的只读镜像，不展示问候头部，按相同分类展示全部当日任务及待完成、已完成、已过期状态；已完成任务同样固定归入末尾的“已完成”分组。设备解锁及日期、时间、时区变化时会刷新，并在后台进程重建时使用当天最近一次成功同步的快照兜底。点按小部件任意位置只会进入任务端首页，不会在桌面修改任务。
- 启动图标使用 `drawable-nodpi/ic_launcher_foreground_lemon.png` 的柠檬吉祥物前景，配合自适应图标浅绿色底色。

## 我的成长：真实数据与展示规则

- 页面从当前登录孩子的 `growth_snapshot()` 只读快照取得任务摘要、EXP、勋章进度和最近足迹；星星余额仍取现有真实积分来源。加载、无记录、读取失败分别展示，不用演示数字或零值冒充失败结果。读接口只允许孩子读取本人快照；家长端的 13 条专项手动进度经独立受控接口维护，任务端不能编辑。任务库领域不推动专项勋章；两条任务习惯勋章由真实任务计算。依赖 `:shared` 的 `GrowthRepository` 和 `supabase/sql/20261005_kid_growth_snapshot.sql`；先部署家长端进度能力，再部署孩子端只读快照。
- 四张统计卡显示有效完成任务数、打卡天数、已获得的勋章阶段枚数和可用星星，数字不带单位。`1` 颗有效任务到账星星计 `1 EXP`，不消耗星星余额，也不把奖励兑换、退款或家长人工积分计入 EXP。总等级从 Lv.1 至 Lv.85，星星、月亮、太阳依次进位，四太阳后为“柠檬之冠”；任务完成、撤销等事实变化可使 EXP 与等级变化。顶部白色资料卡显示孩子头像、等级与勋章称号和今日真实任务打卡。等级卡首行显示当前 `Lv.N`、等级图标及名称和“当前成长值”，中间是进度条，下方显示下一等级及差额；满级不显示下一级。当前版本没有成长纪念卡和等级外观解锁入口。
- 勋章馆按“全部/语文阅读/英语/数学/生活实践/成长习惯”筛选，主列表一类一卡，只展示累计进度大于零的类型；有正数进度但未获首级的类型仍可查看。类型卡等高，显示到下一门槛的真实进度条，点击后查看该类型全部等级的名称、门槛、临时图标及“已获得/未获得”状态。每个已获得的等级阶段独立计一枚勋章，六级类型满级计六枚；顶部和馆内数量都按阶段枚数计算。13 条手动专项加两条任务习惯共 15 条类型；高效英语和思维火箭尚未制定等级。每类各阶段暂复用本地矢量图标，逐等级图片生成、Supabase Storage 托管与加载留待后续需求。
- 最近成长足迹按可核实事件倒序最多读取 10 条，默认显示 3 条，可用箭头展开剩余最多 7 条并收起。足迹日期按上海时区显示 `yyyy-MM-dd`，无法解析时不展示原始字符串；当前勋章类型卡和详情不显示更新时间。无进度分类与无足迹均显示空状态。进入成长页和从后台恢复会重新读取快照，账号切换后清除旧快照。

## UI 参照顺序

柠檬任务的 UI 修改必须先通过 Stitch MCP 获取目标屏幕的实际截图和 HTML，以 MCP 实际效果为主要依据；MCP 缺失或不明确的部分才参考本地下载的 `ui` 目录。此规则适用于本次及后续修改。具体屏幕和例外须记入对应的 `docs/20260922-kid-task-app-*` 需求与设计文档，不扩展到其他应用或全局规范。
