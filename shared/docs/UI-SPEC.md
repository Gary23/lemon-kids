## 一、设计系统

### 1.0 UI 框架方案说明

**Android Compose 生态与前端不同：没有专门的"儿童 App UI 组件库"。**

Material 3 就是 Compose 世界里的"热度最高的 UI 组件库"（Google 官方、所有 Compose App 都在用）。方案是：**以 Material 3 为基础组件库 + 自定义儿童主题 + 配套动画库**，而不是引入额外的第三方 UI 库。

**Kid 端 TabBar** 采用悬浮卡片式设计：28dp 圆角容器 + 粉色柔光投影 + 左右留白，选中态粉色半透明指示器（PinkSoft 0.3f）。图标使用 Material Icons Extended 可爱风格：Checklist（📋 任务）、CalendarMonth（📅 日历）、CardGiftcard（🎁 奖励）、ChildCare（👧 我的）。共4个 Tab。

| 层次 | 方案 | 说明 |
|------|------|------|
| 基础组件 | **Material 3**（`androidx.compose.material3`） | Button、Card、Dialog、Scaffold、BottomSheet 等全部来自 M3 |
| 主题定制 | 自定义 `MaterialTheme`：替换 `ColorScheme` + `Shapes` + `Typography` | 不改组件代码，只改主题参数就能出儿童风格 |
| 动画效果 | **Lottie Compose**（`com.airbnb.android:lottie-compose`） | 任务完成放星星动画，积分到账放金币动画 |
| 庆祝特效 | **Konfetti**（`nl.dionsegijn:konfetti-compose`） | 全部任务完成撒花效果 |
| 内置动画 | **Compose Animation API**（系统自带） | 卡片切换、积分飞入、按钮缩放（不需要额外依赖） |

### 1.2 字体与间距

- 孩子端字体比家长端大 2sp（标题 24sp vs 20sp，正文 16sp vs 14sp）
- 卡片圆角 16-24dp，按钮圆角 20-28dp（胶囊形，孩子端）/ 12dp（家长端）
- 卡片间距 12dp，页面水平内边距 16dp

### 1.3 柱状图组件 (TooltipBarChart)

全局复用的柱状图组件，使用场景包括日视图整点分布、周视图每日总计、单应用详情页。

- **颜色跟随主题**：普通柱子 `primary → primaryContainer` 渐变（绿色系），选中柱子 `secondary → tertiary` 渐变（黄→橙）
- **入场动画**：交错弹出（`tween 600ms + idx*30ms delay`）
- **交互**：点击柱子 → 选中态变色 + 顶部弹出圆角悬浮数值标签（药丸样式，带投影）
- **底部标签**：选中态加粗高亮
- 定义在 `UsageDetailScreen.kt` 中，同包内所有页面复用

- **数据源**：`observeChildTasks` 获取全部任务，内存中按日期分类过滤
- **今日任务**（`dueDate == today`）：按 PENDING→DONE→其他排序，默认展开
- **忘记做的任务**（`dueDate < today && status == PENDING`）：日期降序，默认折叠
- **之后的小任务**（`dueDate > today`）：日期升序，不限状态，默认折叠
- 三个分组主题色：今日=粉色🌸 / 忘记做=珊瑚橙🍊 / 之后=淡紫💜
- 分组标题含 emoji + 标题 + 数量胶囊标签 + 折叠箭头，白底卡片+淡色标题条
- 每个任务卡片左侧有对应颜色装饰条，内含 🔊 语音朗读按钮
- **已完成任务卡片**：薄荷绿底， Checkbox 圆形图标 + 删除线标题 + "撤销"文字按钮
- **过期任务卡片**：灰色底，钟表图标 + "⏰ 已错过 · 截止 HH:MM" + "补做啦"珊瑚橙按钮

```
│  （无任务时显示 🌈 + "暂无计划任务"）│
└─────────────────────────────────────┘
```
- 展示范围：今天→本周周日；若今天是周六/周日→下周一到下周日
- 仅显示状态为"未完成"的未来任务
- 淡紫色（LavenderSoft 0.3f）底色卡片，白色内嵌任务行
- 标题格式：`YYYY年MM月DD日计划`

### 2.5 浮窗组件 (FloatingWidget)

```
浮窗规格: WRAP_CONTENT 自适应大小（实际约 80x40dp）
位置: 默认屏幕左上角 (50, 200)，支持拖动
背景: 圆角白底浅阴影 (floating_bg drawable)
内容: 
  - 本次还可用 / 今日还可用
  - 剩余时间（1 分钟以内显示秒，大于 1 分钟只显示分钟）
  - 横向进度条
```

**当前实现：** 纯 Android View（LinearLayout + TextView + ProgressBar）。无障碍开启时只由 `AppLimitAccessibilityService` 显示 `TYPE_ACCESSIBILITY_OVERLAY`；未开启无障碍时由 `LimitEnforcementService` 显示普通 `TYPE_APPLICATION_OVERLAY`。浮窗只做剩余时间提示，不承担强制阻挡；到达限制后通过无障碍返回桌面并展示阻挡反馈页/通知兜底。

展示规则：如果某 App 同时设置了单次使用时长和冷却间隔，且当前存在活跃会话，浮窗固定展示 `本次还可用`；否则展示 `今日还可用`。

## 六、关键交互细节

### 6.1 首次启动引导

以下是孩子任务端与家长端的引导设计参考；当前绑定码/登录启动路径以对应 `*NavGraph.kt` 为准：

**孩子端 — 3 步引导：**
1. "欢迎来到柠檬小管家！"（欢迎页）
2. "完成每天的任务，就能获得星星积分哦！"（任务说明）
3. "妈妈需要我帮忙开启'使用情况监控'才能管理平板时间" → [去开启] 按钮跳转系统设置（Usage Access + 浮窗权限）

**家长端 — 3 步引导：**
1. 创建家庭（输入家庭名称 → 生成邀请码）
2. 孩子端输入邀请码加入家庭
3. "记得授权通知权限，这样孩子完成任务你就能第一时间知道啦" → [去开启]

### 6.2 任务完成动画

孩子点击"我做完啦" → 确认弹窗 → 确认后：
1. 卡片播放微动画（缩放 + 变绿 + 勾出现，400ms）
2. 积分从卡片"飞入"顶部积分栏（Lottie/Compose 动画，600ms）
3. 如果今天所有任务都完成，弹出庆祝动画

### 6.3 奖励兑换 toast

孩子兑换奖励成功 → 底部弹出 snackbar "兑换成功！等妈妈确认后就能获得冰淇淋啦～"（3秒消失）

### 6.4 空状态处理

- 没有任务的日子：中间显示插画 "今天没有任务，休息一下吧~"
- 没有奖励商品时：奖励页显示 "妈妈还没放奖励进来哦，问问她吧～"
- 监控没有数据时（刚安装）："正在收集数据，明天就能看到报告啦"

### 6.5 异常状态

- 网络断开：顶部红色横幅 "网络断开了，操作会在联网后自动同步"
- 权限未授权：对应功能页面显示引导卡片，点击跳转系统设置
- 数据库读取失败：卡片显示重试按钮 + 错误描述
