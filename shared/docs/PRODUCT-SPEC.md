## 一、产品概述

### 1.1 产品定位
"柠檬小管家"是一套面向家庭的亲子管理工具，帮助家长布置和管理孩子的日常任务，培养孩子的时间管理和自我驱动习惯，同时提供安全的设备使用监控。

### 1.2 核心价值
- 让孩子对"完成任务 → 获得奖励"有清晰预期，培养内驱力
- 让家长远程了解孩子的任务进度和设备使用情况，减少焦虑

## 二、用户画像

### 孩子（6~12岁）
- 有自己的一台安卓平板
- 认识基础汉字，但阅读长文本吃力
- 对视觉反馈（动画、徽章、积分增长）敏感
- 需要被引导，但不喜欢被命令

### 家长（父母一方或双方）
- 使用安卓手机
- 每天下班后或午休时查看孩子情况
- 希望设置任务有灵活性（临时的、重复的、固定时间的）
- 担心孩子沉迷平板，但又不想完全禁止

## 四、用户故事

### 4.1 任务模块

**US-03: 孩子查看今日任务**
> 小明早上打开平板 → 首页看到今天有 3 个任务卡片：背古诗、练字帖、整理书桌 → 每个卡片显示积分值（完成可得 ★5）。

**US-03b: 孩子听任务朗读**
> 小明还不认识所有字 → 点击任务卡片上的🔊喇叭按钮 → 卡通女声读出"背古诗"和任务描述 → 小明知道要做什么了。

**US-04: 孩子完成任务**
> 小明完成练字后 → 点击"我做完啦" → 弹窗确认"真的做完了吗？撒谎会扣分哦" → 确认 → 积分 +5，卡片变绿打勾。

**US-05: 家长创建任务**
> 妈妈在日历上点明天 → 创建任务"完成口算练习" → 设置积分 ★10 → 设置截止时间 18:00 → 明天小明的平板就会显示这个任务。

**US-06: 家长日历管理**
> 妈妈打开日历视图 → 月视图看到每天的任务密度（颜色深浅） → 点某天看到任务列表 → 可拖拽调整日期或修改。

### 4.3 奖励模块

**US-07: 孩子兑换奖励**
> 小明攒了 30 积分 → 点进"奖励商城" → 看到"看动画片 20 分钟"需要 30 分 → 点击兑换 → 积分扣减 → 兑换记录通知发给妈妈。

**US-08: 家长配置奖励**
> 妈妈设置奖励商品："周末去游乐园"价格 100 积分、"吃冰淇淋"价格 20 积分、"看动画片 30 分钟"价格 30 积分。

### 4.4 应用监控模块

**US-09: 家长查看使用报告**
> 妈妈打开监控页面 → 看到今天使用情况：B站 45 分钟、小游戏 10 分钟 → 柱状图展示近 7 天趋势 → 发现 B 站连续 3 天超时。

**US-10: 家长设置限时**
> 妈妈给"B站"设置每日上限 30 分钟、单次最多 20 分钟、超时后休息 5 分钟 → 小明平板浮窗显示“本次还可用/今日还可用” → 超时后通过无障碍服务返回桌面并显示阻挡反馈。

**US-11: 孩子看浮窗**
> 小明打开受限 App → 屏幕上出现可拖动小浮窗 → 显示本次或今日剩余可用时间和进度条。

## 五、业务规则

### 5.1 任务生命周期
```
[家长创建/编辑/删除任务] → [任务出现在孩子端] → [孩子点"完成"]
    → [积分自动到账] → [家长收到完成通知]
```

**重要规则：**
1. 孩子标记完成后积分**立即**到账，任务默认标记为“已通过”，不需要等待家长确认，也不提供家长驳回操作。
2. 过期未完成的任务标记为"错过"，扣少量积分（如 -2），自动产生一笔扣分流水。
3. 家长可以设置某些任务需要"拍照确认"才视为完成。

### 5.2 奖励商品
1. 家长创建奖励时定义：名称、所需积分、是否可重复兑换。
2. 孩子兑换后家长收到通知，由家长决定何时兑现。
3. 积分不可为负数，积分不足时兑换按钮灰色。

### 5.3 应用监控
1. 数据采集每 15 分钟执行一次（WorkManager 定时任务）。
2. 受限 App 在前台时，浮窗显示剩余可用时间，并区分“本次还可用 / 今日还可用”。
3. 限时到达时，通过无障碍服务返回桌面，并展示阻挡反馈页或通知兜底。
4. 支持三种限时模式：每日总时长上限 / 单次连续使用上限 / 单次超时后冷却间隔。
5. 监控数据保留 30 天自动清理。

## 六、页面结构

### 6.1 孩子任务端 — 4 个 Tab

```
┌─────────────────────────────────┐
│ [任务] [日历] [奖励] [我的]       │  ← 底部导航
└─────────────────────────────────┘

首页（任务面板）:
  ├── 顶部：积分余额 + 连续打卡天数
  ├── 中部：今日时间轴（上午/下午/晚上）
  │     ├── 待完成（白色卡片）
  │     ├── 已完成（绿色卡片+勾）
  │     └── 已错过（灰色卡片）
  └── 角落：浮窗（使用时间小圆圈）

奖励页:
  ├── 顶部：当前积分
  ├── 中部：奖励商品网格
  └── 底部：积分流水

日历页:
  ├── 月历任务状态标记
  └── 选中日期的任务列表

我的:
  ├── 头像/昵称
  ├── 今日使用时长
  └── 设置（退出登录等）
```

### 6.2 家长端 — 3 个 Tab

```
┌───────────────────────────────────────┐
│  [任务+日历] [监控] [我的]              │
└───────────────────────────────────────┘

任务+日历:
  ├── 切换：今日列表 / 月日历视图
  ├── 月日历：每天显示任务数量圆点
  ├── 点击某天 → 显示当天任务列表
  └── +按钮创建任务

监控页:
  ├── 顶部：孩子设备今日总使用时长
  ├── 中部：App 使用柱状图（今日）
  ├── 下部：近 7 天趋势图
  └── App 列表（每个可点开设置限时）

我的:
  ├── 家庭管理
  ├── 奖励商品配置
  └── 设置
```

## 七、非功能需求

| 维度 | 要求 |
|------|------|
| 实时性 | 任务变更 3 秒内同步到对端 |
| 离线 | 无网络时孩子可查看已加载的任务，联网后自动同步 |
| 耗电 | 后台监控每小时耗电 ≤ 2% |
| 存储 | 单设备 App ≤ 50MB |
| 隐私 | 使用数据只存储在家庭数据库路径下，不共享 |
| 兼容 | Android 8.0+（API 26+） |
