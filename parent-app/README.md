# `:parent-app`：家长端

## 当前职责

家长登录/注册并创建家庭，管理孩子、任务模板、分类、回收站、奖励与设备使用信息、远程闹钟，并生成孩子任务端或监控端绑定码。

## 任务约束

- 在“我的 > 任务库”创建任务模板（标题、积分，不含日期或描述）。任务库不展示描述，旧模板描述仍保留在数据库，但新排程不继承它。分类管理页将任务模板多选加入分类任务包；同一个任务可属于多个分类。
- 任务库与任务编辑页不再提供“成长领域”“补标”“更正成长领域”入口。数据库中既有 `growth_domain` 字段、历史值和旧 RPC 保留用于兼容，不参与现行专项勋章计算。
- 首页创建任务时可二选一：选择分类任务包后，包内任务横向排列并自动换行，默认全部勾选，可逐项取消或重新勾选；保存仅创建勾选任务，全部取消时不可保存。切换任务包后，新包内任务重新默认全选。选择单个任务则创建一条并在任务端显示为“其他”。随后统一设置执行日期和分配对象，日期区间及重复日程也仅生成选中任务。截止时间不再提供。创建来源在会话恢复后加载；加载失败会提示并可重试，锁屏后返回页面也会尝试恢复加载。此能力依赖先部署 `../supabase/sql/20261010_parent_task_package_selection.sql`。
- 同一孩子、同一日期、同一任务模板只保留一条任务；后一次创建会覆盖该任务的展示分类。分类改名只同步今天及未来尚未完成的任务，既有历史保持原名称。
- 编辑任务模板时，只有服务端确认返回更新记录后才关闭编辑框；保存失败会保留输入内容并显示错误提示。
- 创建任务支持单次日期区间和重复日程（每天、工作日、每周指定日）；重复日程生成独立日任务，以保留逐日完成历史。
- 任务管理列表和日历均同时展示家庭内全部孩子的任务，并按“孩子 → 分类”分段；日历分类仅作分隔，不提供展开或收起。
- 分类标题可取消当前展示日期内的未完成任务，删除前会确认数量；已完成任务和其他日期不受影响。单项删除及分类取消均进入回收站。
- 在任务管理列表创建成功后，使用插入响应的任务 ID 立即合并到已展示的孩子任务列表并结束加载；后台轮询继续以服务端数据校准。列表加载失败时停止加载并显示错误提示。
- 孩子完成任务默认即“已通过”并到账；家长端不再提供驳回操作。
- 家长删除任务实际为取消：仅当天及未来的待完成任务可取消；昨天及以前或已经完成的任务保留为历史。回收站仅能物理清理没有完成和积分历史的已取消任务。
- 任务管理首页列表仅展示当天任务；过去和未来日期的任务统一通过日历视图查看。
- 首页任务列表与日历所选日期任务列表均通过笔图标进入现有编辑页，在“当天任务描述”填写或清空所点任务实例的具体内容；列表项点击不弹出描述编辑框，新建任务页也不提供描述。新任务描述初始为空，旧实例描述保留；过去或已完成任务的描述只读。描述只按 `tasks.id` 写入这一条，普通属性更新及重复日程同步不覆盖其他日期或孩子的描述。保存失败保留编辑内容并提示，部分写入成功会明确提示；列表与任务端读取该实例描述。此能力依赖先部署 `../supabase/sql/20261008_parent_daily_task_description.sql`。
- 家长端在应用运行时收到新完成任务会显示系统通知；离线远程推送未接入。
- 在“我的 > 奖励管理”维护家庭共用的待兑换奖励：创建、编辑、停用和启用，设置正整数价格、一次性或常规类型、说明及大心愿。新增和编辑时无需选择封面，无上传图片也可保存。同一家庭最多一个启用的大心愿；停用保留奖励历史。孩子已兑换奖励的使用、取消及退星由孩子端独立处理。
- 在“我的 > 勋章进度”选择孩子，分别录入 13 条专项勋章的累计完成数量；可调低纠错。认字、默写计字，成语和单词计个，古诗词计首，迪诺英语和思维启萌计课，英语阅读计读物篇数，其余计次。英语阅读 A～Z 逐级录入，每级有固定篇数上限；页面显示中文级名、当前值、阶段和下一门槛。高效英语、思维火箭等级尚未开放。任务担当者、坚持足迹仍由任务事实统计，不提供手动录入。
- 每张专项勋章卡可点“查看详情”打开只读弹窗，滚动查看全部等级的名称、本级经验值和累计门槛。固定上限项目显示 6 级，学期项目显示 12 级并单列六年目标；英语阅读显示 A～Z 共 26 级的本级篇数和完成本级后的累计篇数。勋章经验值按该勋章的单位计量，与任务总等级 EXP 分开；查看详情不会修改进度。
- 勋章保存按孩子隔离并核对服务端结果；真正的版本冲突提示最新值、保留当前输入供家长核对。失败时不显示含请求头的底层异常。现行专项进度只由家长录入，与任务完成、任务库和积分无关；孩子端的读取与展示按独立流程交付。
- 新增或编辑奖励时可从相册选择一张静态 JPEG、PNG 或 WebP 图片，预览后保存，也可替换或移除；图片会缩至最长边不超过 1600 像素并转为不超过 5 MB 的 JPEG，WebP 原文件和动画不会保留。列表及再次编辑时优先显示上传图片，无图或加载失败时显示浅灰色图片区；读取失败可重试，读取或上传失败会提示错误，保存失败不写入失效图片路径。图片只对本家庭已登录成员可读，仅本家庭家长可上传或删除。上线前须先部署 `../supabase/sql/20261004_reward_images.sql` 的字段与私有存储桶迁移。

## 路由与跨端约束

- “我的 > 认字诊断记录”按当前家庭的孩子查看近 24 小时最多 50 条未通过朗读记录。进入及重新可见时加载，可手动刷新；页面可见时每 15 秒刷新，显示设备本地时间的上次刷新时间。切换孩子会清空旧孩子记录。CLS 投递可能延迟；空列表只表示本次未查到匹配记录，查询失败与未配置服务分别提示。
- 记录列出字、词、句目标、标红字和中文判定原因，详情保留腾讯逐项评分与可复制的评测原文。旧记录或原文不可用时说明原因。“字段说明”页解释腾讯官方已定义的字段、枚举及特殊值并提供官方链接，同时区分柠檬认字生成的原因代码。`PronAccuracy=-1` 表示腾讯判为完全不匹配，不能据此认定孩子未开口；腾讯 `Word` 也不是实际语音转写。
- 查询经 `evaluate-reading` 云函数验证家长身份和家庭关系，只返回所选孩子的受限诊断内容；客户端不持有 CLS 密钥。依赖认字端上报 `READING_EVAL_FAILED`、现有 SCF 日志投递至可检索的 CLS 主题、`LITERACY_CLS_TOPIC_ID` 和现有 CAM 身份的 `cls:SearchLog` 权限。详见 [`evaluate-reading` 部署说明](../cloud-functions/evaluate-reading/README.md)。

- 未登录依次使用 `login`、`register`、`create_family` 路由；已登录进入 `main`。
- 主 Tab 为 `tasks`、`alarm`、`monitor`、`profile`。闹钟是独立页签，不能放入监控页；编辑、家庭管理、分类、回收站和设备日志都是子路由。
- 家庭页生成 `task` 或 `monitor` 绑定码，并在进入页面时查询、展示已有的活跃绑定码；协议和重绑规则归 `:shared` 与 Supabase RPC，家长端不得自行生成或保存孩子凭据。
- 任务、积分、分类和监控数据均按 `family_id` 隔离。改查询或写入前检查 RLS 与共享 Repository。
- 勋章进度依赖先部署 `../supabase/sql/20261005_parent_badge_progress.sql`；家长通过受控 RPC 按孩子设置绝对值并留下审计，孩子只读本人进度，其他家庭不可访问。级别规则由 `:shared` 的 `BadgeCatalog` 提供。

## 管理页面加载与失败恢复

“我的”中的任务库、分类管理、回收站、奖励、勋章进度、设备日志和诊断记录在数据加载失败时显示提示；支持重试的入口可在服务恢复后重新加载。已有数据尽量保留，加载失败不作为空数据处理。分类、任务库与分类关联分别加载，依赖未就绪时禁止配置任务包及删除分类。页面退出或重试会取消对应加载任务。

本地测试包还依赖对应业务表、RPC 和存储配置；只有核心家庭与用户结构的本地库不能提供完整业务菜单。外部诊断服务需单独配置。

## 本地测试包服务地址

仅显式 `localSupabase=true` 构建的 `.local` 测试包提供本地地址设置，可从启动页、登录页或“我的”进入。普通 debug 与 release 使用线上配置。手机与电脑需处于可互访网络，填写目标本地服务的私有 IPv4 地址和端口；默认端口为 `54421`，USB 调试可使用对应端口的 ADB reverse 与 `127.0.0.1`。

连接前会检查格式和服务可达性，失败时保留页面并提示。地址成功保存后持续保留；切换到不同服务会清除旧会话，经短暂切换页自动重新打开应用，再确认地址进入登录。相同地址且可达时直接继续。重启接管失败时显示错误或重试提示。测试账号属于对应的本地服务，健康检查成功不表示该服务存在同名账号。

本地构建使用 `./gradlew :parent-app:assembleDebug -PlocalSupabase=true`，并在未提交的 `local.properties` 中设置 `localSupabaseUrl`、`localSupabaseAnonKey`，或通过同名 Gradle 参数、`LEMON_KIDS_LOCAL_SUPABASE_URL` / `LEMON_KIDS_LOCAL_SUPABASE_ANON_KEY` 环境变量提供；仅使用公开客户端 key，缺少配置时构建失败。先准备独立本地数据库核心基线和家长接入 RPC，见 Supabase README。登录会话可恢复，也可退出后重新登录；本地注册与建家庭使用受限 RPC。当前接入范围为认证、家庭和孩子绑定码，其他任务、奖励、闹钟及诊断业务需分别接入验收。
