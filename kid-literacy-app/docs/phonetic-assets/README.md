# 认字词句音素资产概览

词、句的拼音不作为业务数据由 DeepSeek 生成、展示或保存。家长只编辑汉字词句；保存后服务端异步生成腾讯智聆评测所需的音素资产，用于锁定多音字读音。

例如“组长”的“长”按 `zhang` 评测，读为 `chang` 应判错。系统不启用腾讯声调检测，因此仅声调不同不会判错。

## 当前能力

- 待认识和已认识内容的词、句均使用 `literacy_phonetic_assets`；词句朗读通过服务端返回 `TEXT_MODE=1` 参数。
- 服务端使用 `pinyin-pro` 按完整词句生成数字拼音；轻声存为 `null`，不会伪造为一声、`0` 或 `5`。
- “我的 → 待认识的字”可查看并逐字修正音素；词句正文保持只读。
- 内容转入已认识时原子迁移资产；任一入口存入字库时原子清理资产。
