# 柠檬认字 — UI 实现说明

> 适用对象：AI 开发。版本：UI v0.4（花园主题）；范围：横屏平板端孩子应用界面。已接入认证、字库查询、真实识字任务及腾讯智聆评测。学习与数据规则见 [LEARNING-RULES.md](LEARNING-RULES.md)。

## 一、模块与运行方式

- 新增独立 Android 模块：`kid-literacy-app`
- 包名：`com.lemonkids.kidliteracy`
- 应用名：**柠檬认字**
- 启动入口：`MainActivity` → `LemonLiteracyApp`
- 构建命令：`./gradlew :kid-literacy-app:assembleDebug`
- 自动验证：`./gradlew :kid-literacy-app:assembleDebug :kid-literacy-app:lintDebug :kid-literacy-app:testDebugUnitTest`
- 方向：`sensorLandscape`，支持两个横屏方向；共享登录组件沿用原模块。

该模块依赖 Android Compose、`:shared`、Hilt 和 Supabase。孩子通过共享绑定码登录；字库通过 `KnownCharacterRepository` 查询 Supabase 的 `known_characters` 表。

## 二、按页面验收

### 登录凭证恢复弹层

- 启动恢复或任意受保护业务请求发现本地登录凭证不可用时，由应用根层展示，必须覆盖朗读、智能添加识字等其他业务弹层。
- 弹层不可通过返回键或点击遮罩关闭；提供“重试刷新”和“使用绑定码登录”。恢复进行中禁用两个按钮并显示进度。
- 刷新或本机保存的已验证 `task` 绑定码恢复成功后自动关闭；失败时显示原因并允许再次操作。

### 首页

- 花园场景下展示柠檬标志、孩子姓名、欢迎插画和真实任务分组；待认识组采用珊瑚浅底并排在绿色复习组之前。每行最多六个字，窄窗口或大字体时换行；不足六字保持字格尺寸，完成态同时展示颜色和标记。
- 标题右侧提供“刷新”，重新查询云端认字状态，查询期间不可重复点击。保留真实加载、空状态和悬浮返回顶部，不提供人工状态切换入口。
- “认字 / 我的”胶囊导航位于页面滚动内容末尾，短内容时靠底部；标题、任务分组和导航纳入同一纵向滚动布局。
- 任务分组、完成态、字格数量和当天快照遵循 [学习与数据规则](LEARNING-RULES.md)，不在本文重复定义。

### 单字学习弹层

- 点击首页单字后，在统一学习弹层中按“字 / 词 / 句”分区展示；待认识字显示三个分区，已认识字复习只显示“字 / 词”，不显示句分区标题。词一词一行；未满星项在自身边框内显示星星、五点朗读动画和操作按钮，满星项仅展示内容与星星，隐藏朗读按钮与五点动画，内容溢出时可上下滚动。
- **固定布局约束（强制）**：同一窗口与字体设置下，星位、正文、动画、按钮和两行提示槽共用 `StudyPracticeRow`，不得因准备、录音、评测、错误或满星状态改变尺寸、位置和滚动偏移。标准操作区宽 172dp，按钮宽 82dp，按系统字体统一扩展；窄窗口整体改为纵向排布。最后一颗星点亮时立即移除按钮与动画的可见内容、交互和焦点，保留外层槽位尺寸，不能让其他元素扩张、收缩或位移。完整错误提示可通过信息按钮查看。
- 同一时间仅允许一个项目处于准备、录音或等待评测状态，其余项目的开始按钮禁用；结束或得到结果后恢复可操作。当前项目在原位置显示录音和结果状态。

### 朗读反馈弹层

- 当前项目在统一学习弹层内切换为朗读状态，按钮文案依次为“开始 / 读完 / 完成或重试”，并保留关闭叉号、五点录音动画、评测中及结果展示。
- 关闭弹层会取消本次录音或评测并释放资源；未满星时可显示“完成”结束当前反馈，满星即时隐藏操作，不自动关闭弹层。
- 评测结果只在当前弹层标红错读汉字；点读时只以蓝色高亮被长按字，不能使用错读红色。

### 我的

- 展示孩子信息、累计识字数和入口菜单；累计识字数读取本地字库缓存，未缓存时隐藏。
- 麦田场景，真实头像不可用时回退孩子插画。六个入口为已认识的字、待认识的字、字库、帮助过的内容、通过记录和智能添加识字；宽窗口两列三行，窄窗口或大字体时单列。页尾提供“认字 / 我的”导航。

### 已认识的字

- 固定每行三列展示汉字卡，仅显示主字、收录日期及“查看”“置顶”“存库”按钮，不在列表泄露词、句内容。
- “查看”复用待认识字的发音标注弹层，可查看词句并逐字修正数字拼音。“置顶”请求期间按钮显示处理中，列表顺序和收录日期不变，且不可并发置顶；服务端成功返回后，当前页立即将该字移到首位、显示新收录日期及成功提示，无需退出重进，其他字保持相对顺序。失败时列表和日期保持原样并显示错误，可重试；成功置顶使该字重新进入首页三天学习周期。点击“存库”后先显示确认弹窗，手动确认后才提交。
- 窄卡片内部动作纵向排列，请求状态保持按钮高度；页头、统计、字卡与尾部提示在同一滚动网格中。

### 待认识的字

- 每次进入全量读取未完成的 `child_literacy_characters`，仅以自适应汉字网格展示主字。
- 验收加载中、空状态和加载失败状态。

### 发音标注

- 从待认识和已认识列表进入；宽窗口词语、句子双栏，窄窗口或大字体时纵向排列，词句正文只读。
- 每条 `PhoneticAsset` 独立编辑并保存，不使用整窗统一提交；`null` token 表示轻声，不可编辑，不伪造数字声调。保留保存中、成功和错误反馈，关闭可达。

### 智能添加识字

- “我的”进入，去重后最多 12 个汉字。预览显示真实生成内容、已存在提示与可删除分组；字不可编辑，词句可编辑，保留添加到待认识和已认识两种动作。业务校验、保存与音频生成规则见 [学习规则](LEARNING-RULES.md#智能添加识字)。
- 输入、预览分组和末尾确认纳入可滚动表单；键盘出现后保存动作可达。

### 帮助过的内容

- 每条能定位标红汉字的帮助记录提供“加入已认识”和“删除”；无法定位目标字的旧记录不可收录。点击收录先检查当前孩子的已认识状态：已认识则弹窗提示，无内容或时间改动，也不删除记录；仅在字库中的字继续打开单字编辑弹层。检查失败显示错误并允许重试。
- 编辑弹层复用智能添加识字样式，目标字固定，词句可修改，底部只显示“确认并添加到已认识”。保存成功后刷新已认识列表和首页，并移除被点击的一条帮助记录；删除失败时在弹层内提示并允许只重试删除。

### 通过记录

- 桌面场景展示总数、记录时间、来源及通过前完整星级快照；主字、每个词、每个句分别展示真实 `earned / required` 和星位，不能统一为示例五星。
- 保留撤销通过、删除单条和清空全部的确认及请求状态；已撤销记录展示撤销时间，继续保留快照。

### 字库

- 书架场景展示当前孩子的本地缓存，搜索仅过滤缓存，自适应网格不提供拼音分组或索引；没有“加载更多”。进入页面没有缓存时不自动联网。
- 点击“更新字库”才按每批 100 字全量拉取 Supabase 数据、去重并覆盖缓存；更新期间显示阻止重复操作的进度弹层，失败保留旧数据并可重试。我的累计数仅在 `hasLocalData` 为真时显示。
- “导出字库”使用完整缓存顺序，不受搜索影响；序号从 1 开始且包含首尾，结束必须大于开始，开始越界报错、结束越界截断。系统文件窗口保存 UTF-8 文本，汉字以顿号分隔。
- 加载、未缓存、空缓存、无搜索结果、更新失败和导出结果均使用 `LibraryViewModel` 的真实字段，不使用静态字库或人工切换。页头、统计/搜索/导出工具和汉字网格共用纵向滚动。

## 三、设计系统

- 层级：固定无字场景背景 → 可滚动奶油面板和独立插画 → 弹窗遮罩。首页/学习为花园，我的为麦田，待认识/已认识为各自花园，字库为书架，帮助为阅读角，通过记录为桌面。
- 面板：奶油白 `#FFFDF4`；正文深蓝 `#061A39`，次级文字 `#687D9F`。
- 操作：蓝 `#2E9DFF`、绿 `#31B541`、黄 `#FFDA4C`、珊瑚 `#FF6B70`；错读专用红 `#BA1A1A` 与点读蓝分开。
- 组件：面板 28–36dp 圆角、字卡 16–22dp 圆角、浅描边和阴影、渐变胶囊按钮；触控目标至少 48dp，遵守系统字体缩放。
- 字格和练习主字使用完整 Ma Shan Zheng 手写字体，缺字回退系统字体；UI 正文、输入、数字拼音及词句使用系统字体。字体与 OFL 许可随 APK 打包。
- 所有完整页面纵向滚动且无可见滚动条，列表页头和工具栏随列表滚动；主要表单使用 `GardenDialogFrame` 单一内容滚动，关闭附着可见外壳，处理系统安全区、键盘及末尾操作可达性，遮罩阻止底层点击。会话恢复继续保持最高覆盖优先级。

识字内容来自 `child_literacy_characters`，已认识复习内容来自 `recognized_characters`，字库内容来自 `known_characters`。待认识字学习弹层固定使用 `字 / 词 / 句` 三个独立边框区域；已认识字复习只使用 `字 / 词` 两个区域。

## 四、朗读与点读交互验收

- 学习弹层中的字、每个词，以及待认识字的每个句均为独立练习项；点击“开始”后在当前位置进入朗读状态。
- 录音中显示“读完”和五点动画；孩子点击“读完”后结算本轮星星。星星不足时按钮恢复“开始”，当前评测完成时显示“完成”以收起该状态；重新呈现的满星项隐藏朗读按钮，评测错误时显示“重试”。字会将未完成次数动态作为重复参考文本评测（如“花花花”、补读时“花”）；词、句为单次评测。
- 评测结果仅在当前项目标红错读汉字；各项目边框内展示星星。按住汉字时，内容容器显示浅蓝背景和蓝色边框，松手即还原。
- 学习纸中有在线音频的内容使用正常蓝/绿学习状态；无音频 URL 的内容使用浅米色背景和暖灰边框，仍可练习并在点读失败时由系统 TTS 兜底。
- 朗读弹层内词语使用 `40sp`、句子使用 `34sp`，词和句字间距为 `1.5sp`；词、句点读时仅以蓝色高亮被长按字，不能使用错读红色。

## 五、验证与后续优化

布局策略、标准/窄屏大字体练习状态的槽位与滚动偏移、长表单关闭和末尾动作由单元及 Robolectric Compose 测试覆盖。真机录音、网络、键盘、比例与无障碍仍需设备验证，不能用布局测试替代。

本次花园 UI 已安装到 BZT3-AL00，用户确认本轮测试通过；尚不完善的 UI 由后续独立需求优化。该确认不等于已取得所有机型、比例与业务场景的逐项测试记录。交付结论见 [执行记录](../../docs/20261013-kid-literacy-app-garden-ui-redesign/执行.md)。
