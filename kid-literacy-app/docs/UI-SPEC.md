# 柠檬认字 — UI 实现说明

> 适用对象：AI 开发。版本：UI v0.3；范围：平板端孩子应用界面。已接入认证、字库查询、真实识字任务及腾讯智聆评测。学习与数据规则见 [LEARNING-RULES.md](LEARNING-RULES.md)。

## 一、模块与运行方式

- 新增独立 Android 模块：`kid-literacy-app`
- 包名：`com.lemonkids.kidliteracy`
- 应用名：**柠檬认字**
- 启动入口：`MainActivity` → `LemonLiteracyApp`
- 构建命令：`./gradlew :kid-literacy-app:assembleDebug`

该模块依赖 Android Compose、`:shared`、Hilt 和 Supabase。孩子通过共享绑定码登录；字库通过 `KnownCharacterRepository` 查询 Supabase 的 `known_characters` 表。

## 二、按页面验收

### 登录凭证恢复弹层

- 启动恢复或任意受保护业务请求发现本地登录凭证不可用时，由应用根层展示，必须覆盖朗读、智能添加识字等其他业务弹层。
- 弹层不可通过返回键或点击遮罩关闭；提供“重试刷新”和“使用绑定码登录”。恢复进行中禁用两个按钮并显示进度。
- 刷新或本机保存的已验证 `task` 绑定码恢复成功后自动关闭；失败时显示原因并允许再次操作。

### 首页

- 展示真实识字任务分组、可直接点击的单字格、悬浮返回顶部和底部导航；待认识组排在已认识组之前。
- 验收正常、加载中和空状态；顶部保留仅用于验收的状态切换入口。
- 任务分组、完成态、字格数量和当天快照遵循 [学习与数据规则](LEARNING-RULES.md)，不在本文重复定义。

### 单字学习弹层

- 点击首页单字后，在约 90% 宽高的弹层中按“字 / 词 / 句”分区展示；待认识字显示三个分区，已认识字复习只显示“字 / 词”，不显示句分区标题。词一词一行；未满星项在自身边框内显示星星、五点朗读动画和操作按钮，满星项仅展示内容与星星，隐藏朗读按钮，内容溢出时可上下滚动。
- 未满星项的内容区与右侧动画、按钮区预留固定尺寸，状态切换不得改变行高或横向宽度；句子文本块整体居中，多行文字左对齐。
- 同一时间仅允许一个项目处于准备、录音或等待评测状态，其余项目的开始按钮禁用；结束或得到结果后恢复可操作。当前项目在原位置显示录音和结果状态。

### 朗读反馈弹层

- 当前项目在统一学习弹层内切换为朗读状态，按钮文案依次为“开始 / 读完 / 完成或重试”，并保留关闭叉号、五点录音动画、评测中及结果展示。
- 关闭弹层会取消本次录音或评测并释放资源；达到所需星星后按钮显示“完成”，不自动关闭弹层。
- 评测结果只在当前弹层标红错读汉字；点读时只以蓝色高亮被长按字，不能使用错读红色。

### 我的

- 展示孩子信息、累计识字数和入口菜单；累计识字数读取本地字库缓存，未缓存时隐藏。
- 提供已认识的字、待认识的字和字库跳转入口。

### 已认识的字

- 展示已掌握学习卡列表和详情学习卡弹窗。
- 右侧“查看”“存库”使用 64dp 宽的紧凑按钮；验收下载成功和入库成功反馈。

### 待认识的字

- 每次进入全量读取未完成的 `child_literacy_characters`，仅以自适应汉字网格展示主字。
- 验收加载中、空状态和加载失败状态。

### 字库

- 从 Supabase 分页加载，支持汉字搜索和自适应汉字网格。
- 首次读取 100 个字，点击“加载更多”继续读取下一页；按收录时间展示，不提供拼音分组或索引。
- 验收加载中、无字库、无搜索结果、加载失败后重试和加载更多状态。字库使用 `LibraryViewModel` 的真实 `Loading / Empty / Content / Error` 状态，不使用静态字库或人工切换。

## 三、设计系统

- 背景：奶油浅黄 `#FFF9E8`
- 主色：天空蓝 `#62B6E8`
- 已完成：草绿 `#65B96B`
- 待学习/鼓励：珊瑚橙 `#F28B63`
- 装饰与积分：小麦黄 `#F4C95D`
- 组件：14–30dp 圆角、浅描边、低对比阴影、较大字号与点击区域

识字内容来自 `child_literacy_characters`，已认识复习内容来自 `recognized_characters`，字库内容来自 `known_characters`。待认识字学习弹层固定使用 `字 / 词 / 句` 三个独立边框区域；已认识字复习只使用 `字 / 词` 两个区域。

## 四、朗读与点读交互验收

- 学习弹层中的字、每个词，以及待认识字的每个句均为独立练习项；点击“开始”后在当前位置进入朗读状态。
- 录音中显示“读完”和五点动画；孩子点击“读完”后结算本轮星星。星星不足时按钮恢复“开始”，当前评测完成时显示“完成”以收起该状态；重新呈现的满星项隐藏朗读按钮，评测错误时显示“重试”。字会将未完成次数动态作为重复参考文本评测（如“花花花”、补读时“花”）；词、句为单次评测。
- 评测结果仅在当前项目标红错读汉字；各项目边框内展示星星。按住汉字时，内容容器显示浅蓝背景和蓝色边框，松手即还原。
- 学习纸中有在线音频的内容使用正常蓝/绿学习状态；无音频 URL 的内容使用浅米色背景和暖灰边框，仍可练习并在点读失败时由系统 TTS 兜底。
- 朗读弹层内词语使用 `40sp`、句子使用 `34sp`，词和句字间距为 `1.5sp`；词、句点读时仅以蓝色高亮被长按字，不能使用错读红色。
